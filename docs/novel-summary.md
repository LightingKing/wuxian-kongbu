## 一、一句话概括

厌倦人生的白领郑吒点下"想明白生命的意义吗？"弹窗里的 YES，被拉进由「主神」掌控的轮回世界：轮回者被一次次投入恐怖片（后期也有科幻、战争、奇幻片），靠完成任务赚奖励点数和支线剧情，在主神空间兑换血统、技能和装备不断变强。郑吒从新人成长为中洲队队长，与伙伴们经历一次次团灭、复活、背叛与牺牲，最终在"最终一战"中击败恶魔轮回小队的队长——他自己的复制体，而几乎所有伙伴都在这一战中战死。

## 二、世界观与核心规则

### 2.1 主神与主神空间
- **主神**是悬浮在广场中央的光团（光球），会发布任务、结算奖励、回答部分问题，也会改写剧情、提高难度、抹杀违规者。
- **主神空间**：中央光团，四周 20 个房间（只有被允许的人能进），房间可按意志改变布置；有地下室或训练场（可扩到数十至上百公里，能造森林湖泊），后期可造"真实创造空间"和虚拟幻境。每部恐怖片之间通常休整约 10 天。
- 进入恐怖片前要在 30 秒内踏入光柱。恐怖片里的时间在主神空间只是一瞬。
- 只要意识清醒回到主神空间，伤势和病毒都能被修复（"全身修复"要花点数）。

### 2.2 恐怖片任务
- 手表显示任务、倒计时、击杀计分。基础任务通常是"存活 N 天/N 小时"或"击杀某目标"，活过一部固定给 1000 点。
- 常见附加限制：不得离开剧情人物 100 米或 5000 米（超出即被抹杀）、不得向剧情人物泄露主神信息（每句扣分）、禁止飞行器、禁止大范围武器等。
- **剧情惯性/剧情修正**：剧情会尽力沿原片走；改变剧情能拿高额奖励，但主神可能提高难度、触发"剧情改变"（几乎必定团灭）。
- 每部片人数约 7~20 人，"N 人难度"表示难度级别，人数越多越难。

### 2.3 奖励点数与支线剧情
- **奖励点数**：杀怪（10 只丧尸 = 1 点、爬行者 100 点、异形 500 点等）、完成任务、改变剧情都能获得。杀新人或队友扣 1000 点；结算后点数为负 = 被抹杀。
- **支线剧情**是兑换高级物品的"门票"，等级 D < 双D < C < 双C < B < 双B < A < 双A < S < 双S。1 个 B = 3 个 C，1 个 C = 2~3 个 D（原文前后两种说法），3 个 B = 1 个 A，可拆可合。难度参考：B 级全灭率约 80%，双B 约 90% 以上。
- 楚轩总结的支线三规律：剧情变化越大奖励越大；危险越大奖励越大；需要合作的对象越多，得奖人数越多。

### 2.4 兑换与强化
- 兑换分四大类（科技类 / 魔法传说类 / 辅助类 / 娱乐类），外加六项基础属性：智力、精神力、细胞活力、神经反应速度、肌肉组织强度、免疫力强度（常人各约 100，10 点奖励点数换 1 点属性）。
- 典型价格：沙漠之鹰（无限子弹）100 点；低级气功 500 点 + D；血族男爵 800 + D；血族子爵 1500 + C；血族伯爵 3000 + B；高斯狙击枪 5000 + D；神血统 5 万 + S；修真 7 万 + S；回归现实 5 万点。
- 魔法传说类约是科技类价格的两倍；同时兑换两种血统约有 70% 几率变异成非人。
- A 级及以上的内功、技能、血统兑换后"只是心法"，要自己修炼才能发挥；D~B 级即时生效。
- 每人每部片只能给别人兑换一次（点数或支线）。
- 剧情世界里拿到的物品（亡灵圣经、复活真经、审判之矛、至尊魔戒等）可以带回主神空间，属于重要收获。

### 2.5 基因锁（全书核心成长线）
| 阶 | 名称/效果 | 代价 |
|---|---|---|
| 第一阶 | 濒死恐惧中触发，战斗本能、危险预感、痛觉屏蔽 | 事后内脏痉挛、吐血、脱力 |
| 第二阶 | 自由控制肌肉，发挥 90% 以上力量，肌肉膨胀 | 后遗症更重 |
| 第三阶 | "模拟"：用脑电波模拟认识的人的思维、动作、部分能力（约 30~60%） | 久用头痛 |
| 第四阶 | 初级"入微"（唤醒沉睡基因，强化发挥 100%）；中级需度过**心魔**（"大自在"），获得个人化的**心灵之光**；高级可在原子/能量层面精细控制 | 心魔过不去则死亡或沦为无思维的怪物；会唤醒远古基因，影响外形和意识 |
| 第五阶 | 控制能量，近于"圣人" | — |

- 普通人只能发挥兑换属性的约 10%，一阶 20~30%，二阶 40~50%，四阶才是 100%。
- 主神强化最多帮到第三阶，第四阶全靠自己。整个轮回世界达到第四阶的不超过二十人。
- T 病毒原液 / TBD 原液可以人工开启第一阶。

### 2.6 力量体系
- **内力 → 真元力**：气功内功；凝炼成气态的真元力后能驾驭虎魄刀、八卦旗等修真法器。
- **血族能量 → 魔力**：血族血统的能量（红炎、蝙蝠化等）；压缩后成为魔力。真元力与魔力在体内对撞就是郑吒的终极技「洪荒，开天辟地」（原理同楚轩的魔动炮）。
- **精神力**：扫描、心灵锁链（三人共享视野）、心灵鞭挞、思维控制、精神屏蔽。精神力控制者是最稀缺的人才，也是衡量队伍强弱的标志。
- **魔网体质**（龙与地下城式法术，每日次数限制）、召唤卡、果实能力（冰霜、响雷、风风、沙沙……）、狼人/精灵/三眼族等血统。
- **修真**：符文科技（"修真 = 修成真实"，相当于领先千年的科技）；元婴、元神、阵法、飞剑。
- **自创技能**（郑吒的「爆炸」「毁灭」「瞬间毁灭」「洪荒」、李查德的「狂战士」）可 100% 发挥，并且**不计入主神的难度评价**。
- **因果率武器**：信念之力 λ-drive、点线魔眼/方正魔眼、封神榜、引导真实的谎言、现实具化幻想术……"得到多少就要失去多少"（折寿、终生不能睡觉、被宇宙排斥等）。

### 2.7 轮回小队、团战、引导者
- 共 17 支轮回小队，以古代洲域命名（中洲、印洲、南炎洲、北冰洲、东美洲、森洲、西海、东海、北海……），另有两支特殊队伍：
  - **恶魔轮回小队**：主神复制各队强者组成，最强。队长是郑吒的复制体（生化危机一后被复制）。
  - **天神小队**：成员全是基因锁解开者，某人当上队长时会被邀请加入。智者是亚当。
- **团战**：一支队伍累计出现三名基因锁开启者后，开始与别洲队伍在同一部片里相遇。规则是杀对方未开锁成员得 2000 点 + C，杀已开锁成员得 7000 点 + B；己方死一人记 −1 分，杀一人记 +1 分，终分 × 2000 为双方幸存者的奖励，负分则抹杀。"势"（先进场、掌握剧情势力）是团战的重要资源。
- **引导者**：主神制造的虚拟人格，混在队伍里考验队长候选人。考验通过后获得队长资格（可预知下一部片、快速查询兑换、知道更多内情）。张杰就是半个引导者；后期新人杨雪霖也是引导者。

### 2.8 复活、造人、新人、回归现实
- **复活**：神鬼传奇世界的复活真经在祭坛使用，B 级支线 + 7000~8000 点，每人一次；在主神空间复活要付死者生前所得的两倍；首部就死的新人免费复活。后期大家的复活机会都已用完，死亡就是永久死亡。
- **造人**：首次免费制造一个人形生命体（郑吒造了青梅竹马萝丽）。队伍有队长后，造物必须一起进片，或用 D 级支线"赎身"。
- **新人**：每部片补充新人，老手讲解规则（讲解可得 100 点）。新人死亡率极高，常被当作诱饵；《中洲五条》规定了新人入队的投票机制。
- **回归现实**：用生活天数兑换（记录世界 5 倍价），不得泄露主神空间；永久回归需 5 万点。郑吒曾回现实 30 天，被国安局追捕。

### 2.9 难度与评价
- 难度由团队最强者的实力、兑换属性强弱、完成过的片子难度决定（自创技能和开基因锁不计入）。不死人则评价上升，后续片子更危险，也会更早遇到恶魔、天神小队。
- 难度排序：科技类最易 → 科幻 → 魔幻 → 鬼怪 → 科幻战争类和"莫名其妙类"（死神来了）最难；同系列集数越高越难。

### 2.10 深层真相（全书逐步揭示，但没有完全解开）
- 远古的**圣人**（基因锁第五阶）与**修真者**分属黄、白、黑三大肤系，曾在"洪荒大战"中死去七成。他们共建了 34 座主神空间，作为人类的训练营兼避难所，并留下"六大遗产"。中洲队得到黄肤系修真遗产：东皇钟、造化玉碟。
- **盒子理论**：宇宙是一个"盒子"，盒子外的制造者才是圣人与修真者真正的敌人；知情者会被察觉，所以真相不能直说，只能靠实力"考试"。
- **主角理论**（楚轩）：主神空间的用途之一是制造"主角"，"最终一战"争夺的就是主角资格。
- **最终一战规则**：所有队伍进入《生化危机三》。最后只剩一队胜利，可以选择回现实或得知主神空间创造者的留言，各轮回世界随之彻底关闭；活过 100 天并杀十人，或进入第七号实验室待满三小时，可以回主神空间继续轮回；无奖励点数、无负分、禁止大范围武器。
- 全书结尾**没有正面揭示主神真相**。郑吒带着幸存者走向第七号实验室，结局开放。

## 四、分部剧情摘要

### 上半部：初始（生化危机一 → 生化危机二）

**1. 生化危机一。** 郑吒醒在高速列车上，老手张杰向六名新人讲规则：活过一部得 1000 点，攒够 5 万点可回现实，不得离开剧情人物马修 100 米。两名新人掉队，被当场抹杀。激光通道里，郑吒凭电影记忆拖着马修紧贴大门躲过激光网，马修本该死而活下来，郑吒得到"B 级恐怖支线完成，5000 点"。火焰女皇（红后）被关闭后，丧尸、爬行者涌出，四人守在主机房，被传回主神空间。郑吒用首次免费的造人名额造出青梅竹马萝丽，把 B 级支线拆开兑换了气功和血族血统。

**2. 异形一。** 十五人在商船上，任务是杀光异形。新人楚轩（IQ220 的大校）、杀手零点、雇佣兵霸王加入，楚轩讲出"基因锁"理论。楚轩的诱饵计划逼得李帅西自爆，郑吒怒打楚轩、分道扬镳，后来又结成"盟友"。巢穴决战中，郑吒肠断、脊椎折断、被拍成两截，仍用最后一只手把螺旋刺炸弹刺进皇后嘴里引爆。霸王战死。

**3. 现实 + 咒怨。** 郑吒花点数回现实 30 天，带萝丽见了父母，却因楚轩藏在匕首里的定位仪被国安局追捕。回来后他与楚轩决裂。咒怨里二十人要活七天，新人赵樱空、齐腾一加入；新人内斗、偷佛经。楚轩独自死战六波咒怨后身亡，死后鬼魂还替郑吒挡鬼。郑吒推出七波规律，首次主动解开基因锁第二阶，与零点合力击散伽椰子。

**4. 神鬼传奇。** 金色石碑宣告团战开始。中洲队对印洲队（小和尚队长湿婆·甘天、精神控制者雪耐、念力钢针兰姆、狼人阿罗特等），同时要消灭伊莫顿。郑吒夺得亡灵圣经，学会召唤木乃伊侍卫、造龙卷风、改地形。齐腾一、零点相继被兰姆刺死。12 岁的天才萧宏律设下诱饵反制，张恒箭撞箭射杀护盾者。郑吒在祭坛暗巷咬死小和尚，伊芙念咒召来幽冥马车，郑吒斩首伊莫顿。复活真经在逃亡中落崖。休整时张杰讲解基因锁五阶，众人立下《中洲五条》。

**5. 死神来了2。** 张杰精神控制四名队友袭击郑吒：打败四人才能逐步得知真相，打败张杰才能当队长。死神用连锁意外无序杀人，新人和王侠相继惨死。郑吒抢运钞车冲进电视大楼，撕开伤口把血溅到怕血的张恒脸上躲过风之矢，在楼顶痛殴张杰。张杰坦白自己是半个引导者，递烟讲完主神内幕后死去；郑吒获得队长资格和基因锁第三阶。

**6. 异形4。** 全员醒来时被绑在孵化室，萝丽被寄生。郑吒模拟楚轩的冷酷，逼一对科研夫妻取出萝丽体内的皇后。队伍分两路：詹岚用金属片控制两头进化体互相刺死，张恒三重爆裂箭轰碎皇后脑袋，郑吒被进化体一掌拍成重伤飞进救生舱。最高难度完成，异形系列关闭，全员生还。军医程啸入队。

**7. 生化危机二（上半部结局）。** 任务是带博士女儿安吉逃出检查站。郑吒在桥上一拳打飞追踪者，和保护伞公司谈"交易"。恶魔轮回小队降临：复制体郑吒（黑火巨剑、蝙蝠肉翅、黑暗牢笼）两分钟灭掉六架武装直升机。他自述身世：被复制后，萝丽被原恶魔队员凌辱分尸，他在仇恨中变强。中洲队几乎全灭——张恒被复制体铭烟薇射穿心脏，萧宏律、程啸、詹岚等相继被杀。郑吒被斩臂劈头，靠詹岚留给他的重生十字章复活，回到主神空间发誓复活所有人。

### 下半部：暴雨（神鬼重宝 → 生化终战）

**8. 神鬼重宝。** 只剩郑吒一人。他独自回神鬼传奇，雇三千民工挖哈姆纳塔，夺审判之矛和死神手镯，一路过石像、猴子森林（主神给猴子发了枪）、沙尘暴，自创技能「爆炸」，在被剥夺强化的金字塔中与伊莫顿立约合作，刺杀蝎子王。挖出复活真经后，他复活了楚轩，并以"我有办法让你感觉到痛"打动对方；回主神空间后又复活霸王、王侠，并把「爆炸」推进到「毁灭」。

**11. 铁血星河。** 星河战队，三队同场。中洲队降落后灭口随队士兵以隐藏身份，坚守山顶七小时，以"奇迹四人组"造势。南炎洲队智囊尼奥斯指认他们是"虫族寄生者"，楚轩反手公开对方心灵同步的证据，尼奥斯吐血而死。郑吒夺旗舰、击败「狂战士」李查德。七存一作战中，地底猎杀森洲队，零点狙杀脑虫，虫群自相残杀。回空间后复活赵樱空、张恒、程啸。

**12. 偷袭生化。** 回访生化危机，偷 TBD 原液（可开启基因锁第一阶）。郑吒当诱饵被保护伞俘虏，撕开牢笼，召唤上千死神军团，一人屠光百余头巨大爬行者；队友趁机突袭武器实验基地，身后两朵蘑菇云。

**13. 指环战争。** 魔戒，五队同场（中洲、南炎洲、北冰洲、东美洲、天神）。九戒灵每死一只，其余就吸收它的力量变强，郑吒「毁灭」五秒连斩两只并缴获骷髅梦魇。摩瑞亚炎魔被郑吒、赵樱空、北冰洲队长岗尼尔合力击杀。圣盔谷之战中楚轩"心脏被炸碎"，郑吒狂化进入基因锁第四阶。之后才知楚轩是借精灵女王的灵魂保存法假死，识破了卧底昊天（天神队亚当的人），并带追踪者围住天神小队逼其妥协。魔多决战中，郑吒召出四万死神军团；张恒射伤索仑持戒的手臂，赵樱空斩断它抢下至尊魔戒，索仑被主神抹杀。

## 七、主题与结局

- **主题**：在"活下去"的压力下，人性如何选择——孤独的王者之道（复制体：舍弃感情换取力量），还是与伙伴并肩的仁义之道（郑吒）。书中反复对照：郑吒与复制体（感情 vs 仇恨），楚轩与复制体楚轩（感情 vs 利益），楚轩从"无痛无情"到最终落泪说出"感情"。基因锁第四阶的心魔、猛鬼街的心灵漏洞，把"内心的弱点"直接变成战斗机制。
- **结局**：郑吒以伙伴的信念击败复制体，复制体临终坦白自己想要"伙伴和心爱的女人"。但中洲队几乎全员牺牲，主神与盒子制造者的真相、伙伴能否复活（纳尼亚的"第二次复活机会"）都没有交代，结局是开放的。

## 八、对游戏改编最关键的要素（详细方案见后续设计文档）

1. **生存循环**：主神空间（休整、兑换、复活、训练）→ 恐怖片（任务、限时、剧情惯性）→ 结算，正好对应暗黑地牢式的"据点 → 远征 → 结算"。
2. **两种货币**：奖励点数 + 支线剧情（分级、可拆合），兑换门槛由支线等级决定。
3. **基因锁**：濒死触发、阶段解锁，事后有代价；第三阶模拟队友，第四阶心魔关卡。对应暗黑地牢的"压力/崩溃/觉醒"。
4. **剧情知识**：玩家（和郑吒一样）知道电影剧情，可以利用"预知"改变剧情、赚取支线，但会提高难度。
5. **队伍政治**：新人投票、《中洲五条》、诱饵抉择、点数分配、互赠限制、队长与智者的意见冲突。
6. **永久死亡与复活**：复活有门槛、有次数，死亡有真实分量。
7. **团战与"势"**：其他轮回小队是会布局、会谈判、会背叛的对手。
8. **心魔与情感**：心魔与心灵漏洞作为角色专属的成长关卡。
