# 《无限恐怖》核心机制分析（为游戏设计服务）

> 目的：不停留在"原著出现过什么任务、什么价格"，而是分析**为什么这样出题、为什么这样给奖励、为什么选这些人**，提炼成能计算、能生成的规则。这样原剧情模式能复现原著，沙盒模式能生成"像原著"的新内容，主神 AI 也有可遵守的规则。
> 依据：`_work/summaries/s01~s25.md`、`_work/mechanics.md`、`_work/hub.md`；`L数字` = 原文行号。

## 一、主神的行为逻辑：它为什么这样安排

### 1.0 主神是有目的的行动者，不是死物
原文里主神的动词是"察觉""刻意提高""催促""下达最后命令""决定""不希望""试试"。它有目标、有判断、有日程表：
- **目标**：进化。"「主神」……所希望的是进化，而不是玩弄般的将人虐死"（L5636）；恶魔小队和天神小队"也是为了试试什么样的情况更适合进化"（L5619）。
- **标准课程**：每支队伍都走同一套培养流程（见 1.0.1）。
- **异常处理**：流程被打乱时，主神会察觉并纠正，手段可以很狠。
- **对个体的干预**：盯住潜力高的人，替他清除"拖后腿"的因素，或把他复制进恶魔小队。
- **群体实验**：特殊小队就是对照实验（见第十节）。
- **自我约束**：主神遵守自己定下的规定，正常情况下"不会发布绝对必死的任务"，总会留一条出口；还有一点"人情味"——郑吒在把真相说出口之前，随时可以改主意加入天神小队（L5627）。

#### 1.0.1 一支正常队伍的标准课程（据张杰临终坦白复原）
1. **新人期**：主神"并不会让进入这个恐怖片世界的人就这么直接面对危险"，每支队伍里都藏着一个**引导者**（不会真正死亡、不能当主战力），陪队伍走到第一个人解开基因锁为止（L5349、L5548）。
2. **出现第一个开锁者**：引导者必须考验他。主神会"不停催促"，引导者不考验就会被抹杀（L5573）。考验通过 → 引导者与他融合，他获得**队长职务**、基因锁升一阶，**当前恐怖片直接结束**（L5550、L5569）。
3. **天神小队邀请**：成为队长时，主神问他要不要加入天神小队。去了，原队换一个新的引导者，从头再来（L5619、L5625）。
4. **成长窗口**："一般来说，在遇到其余轮回小队前，都会安排几场大奖励点数与支线剧情获得的轻松恐怖片，以此来提高团队的实力……特别是解开基因锁成员的实力"（L5601）。
5. **团战**：累计 3 名开锁者 → 金色石碑 → 与其他洲队伍碰撞（L2758）。
6. **难度上升**：难度按队伍里最强者安排（L5644），评价越高、片越凶险。
7. **潜力追踪**：潜力突然升高的人会被复制进恶魔小队（L7310）。
8. **瓶颈试炼与终局**：第四阶心魔片（猛鬼街三，L17393）；有人接近第五阶时，主神加速各队混战（s12），最终一战。

#### 1.0.2 中洲队的上半部为什么这么难：一个异常
- **张杰是"半引导者"**：他在猛鬼街一里本来通过了考验，融合到一半时本体被 BOSS 杀死，于是他既是队长又是引导者（L5551、L5571）。他不受引导者"不能对队员出手"的全部限制，又能 **100% 发挥**兑换来的双 A 级精神力技能（L5546）。
- **主神察觉异常，刻意加难**："因为我既是中洲队队长，又是引导者身份……所以察觉出不对劲的「主神」，它开始刻意提高中洲队所要面对恐怖片的难度……比如生化危机只有那么几个人的难度竟然到最后都只是险死还生，这在别的队伍恐怕是不会遇到的"（L5595）。
- **难度按最强者算**：最强者就是张杰（L5644）。
- **异形一碰上了随机的"剧情改变模式"**："一旦出现，那就几乎肯定是团灭"，靠郑吒开锁才活下来（L5598）。
- **没有成长窗口**：正常队伍在遇到别队之前会有几部轻松的大奖励片，中洲队一部都没有（L5601）。

所以上半部的残酷不是"主神本来就这么出题"，而是**一支队伍的培养流程坏掉以后，主神一边加压一边强行纠正**。生化危机二之后，异常已经纠正；而且**中洲队团灭了**——所有人都死了，包括郑吒，他只是靠重生十字章复活——评价因此清零（楚轩："可是中洲队失败了，换句话而言，评价分清零……下一部恐怖片，我们将面对普通轮回小队面对的困难等级了，而并非是被「主神」刻意关照的难度等级"，L8006）。中洲队这才第一次走上正常课程：先是普通难度、支线丰厚的片（侏罗纪公园二被判为"普通小队"难度），再进入势均力敌的团战。这正好解释了"过了生化危机二才真正有意思"。

#### 1.0.3 三个关键问题
**为什么前几部那么难？** 见 1.0.2：半引导者异常 → 主神刻意加难；难度按最强者（张杰）定；异形一遇上随机剧情改变；而且没有成长窗口。

**为什么没有队长就开始团战？**
- 团战的触发条件是"累计 3 名开锁者"（石碑，L2758），**和有没有队长无关**。主神的里程碑按"进化指标"触发，不等你的组织准备好。
- 正常流程里，第一个开锁者会先被考验成为队长，然后有成长窗口，然后才团战。但张杰一直拖着不考验郑吒（L5573），流程就错位了：团战先到，队长后到。
- 而且团战来得异常早，张杰自己都说："当你们才知道有其余轮回小队后，马上就遇到了一个轮回小队，这种情况实在是有些不可思议"（L5601）。

**为什么会进死神来了2？那时的中洲队过得去吗？**
- **过不去。** 张杰原话："这一部里，如果按照正常途径，依然我们现在的实力是必死地了"（L5601）。死神系列属于最难的"莫名其妙类"（L5597）。萧宏律也推断，除非队伍很强，否则主神不会把人扔进死神来了这类片（L5646）。
- **它是一道最后通牒。** 张杰在神鬼传奇里出手攻击了别队成员（他反噬了印洲的雪耐），违反了引导者规定，主神"终于是下达了最后命令，而这一部恐怖片，就是我们的命运，要么你死，通不过考验……要么我死，你则得到中洲队长队员的职务"（L5573、L5601）。
- **整部片只有一个出口：完成考验。** 存活 5 天几乎不可能（死神越到后面越肆无忌惮），但"只要打败我，这一部恐怖片就会顺利结束"（L5348）。郑吒打败张杰、融合完毕的一刹那，主神宣布"中洲小队完成任务"，那时坠落的客机正撞向他所在的楼顶（L5612）。连死神的最后一击都卡在考验的终点上。
- **这暴露了主神的一个惯用手法**：当它想推动某个进化步骤时，会设计一个"按正常途径必死"的局面，只留一个出口，而这个出口恰好就是它想要的那一步。

### 1.2 回答你的问题：后期中洲队还会遇到"100 米绑定"吗？

**不会。** 原著里就能看到这条限制随队伍变强而变化：生化危机一是 100 米（普通人跟上特种兵很难）；神鬼传奇一放宽到 5000 米（开锁者跑 5000 米已经不难，但它仍把两支队伍拴在同一个剧情中心）；之后就再没出现过距离绑定。

绑定真正的作用是"**不让你躲开剧情**"。队伍越强，主神就换越强的手段来达到同样目的：
- 保护一个脆弱、而且你的长处派不上用场的目标（哈比人对科技免疫、死神来了里随时会死的普通人）；
- 区域限制（炮击前不得离开华盛顿）；
- 禁掉机动手段（禁飞）；
- 取消倒计时、改成必须完成的击杀任务，或在后期追加任务（星河战队最后 3 天）。

### 1.3 归纳：两层逻辑

**议程层（主神想推动什么）**：
- 按标准课程推进每支队伍（引导者 → 队长 → 成长窗口 → 团战 → 加难 → 瓶颈试炼 → 终局）；
- 察觉异常并纠正（加难、催促、最后通牒、强制关卡）；
- 追踪个体潜力（复制进恶魔小队，清除"拖后腿"的因素，安排瓶颈试炼）；
- 运行群体实验（恶魔、天神、普通队伍三种环境）。

**出题层（用什么手段推动）**，八条原则：

1. **难度相对**：所有难度都相对于"这支队伍现在的评价"来定（L5644、L7867、L21838）。同一个任务，对新人是绝境，对后期中洲队是散步。
2. **克制最强项**：队伍靠什么过关，主神下一次就压什么。躲 → 拿掉倒计时；科技 → 科技无效；扫描 → 屏蔽；剧情知识 → 禁止打听、改写剧情；飞行 → 禁飞；灭城武器 → 禁大范围武器；肉体 → 打不着的敌人、精神攻击。
3. **绑定剧情**：不许置身事外。手段随实力升级：100 米 → 5000 米 → 保护目标 → 区域限制 → 追加任务 → 放大地图逼相遇。
4. **平衡"势"**：团战里弱队先进场、强队受限制（L10528、L20315）。主神要的是势均力敌的厮杀，不是碾压。
5. **动态增压**：场内战力过了临界值，怪物就进化（T 病毒进化）；杀得越多，敌人装备越好（猴子）；关键挑战里剥夺买来的强化。
6. **指向进化瓶颈**：主神的目的是进化而不是杀人（L5636）——"不会发布绝对必死的任务"（L361、L13656），"每部片都有轻松的解法"（L8543）。片和支线往往正对着队伍当下的成长瓶颈（心魔片、生擒精神力控制者、让幼龙长大）。
7. **道德与选择压力**：杀剧情人物扣分、"全灭所有生物"的文字陷阱、新人当不当诱饵、牺牲谁保谁。
8. **威胁等于奖励**：楚轩的原话（L8025）；支线三规律（L8896）：剧情变化越大奖励越大，危险越大奖励越大，合作对象越多得奖人数越多。

### 1.4 可计算的出题模型（给主神 AI 和沙盒用）

**第零步：议程**。主神为每支队伍、每个重要个体维护一份**隐藏议程状态**：
- 队伍处在标准课程的哪一步；
- 有没有异常（例：队长与引导者并存、引导者拖延考验、违规攻击），异常持续了多久；
- 有没有待执行的最后通牒；
- 每个人的潜力值和最近的潜力突变（造人、凭自身属性开锁、心魔突破……）；
- 谁被复制进了恶魔小队；
- 谁在"拖后腿"（主神眼中妨碍高潜力者进化的人或羁绊）；
- 谁卡在什么瓶颈上。

每部片的选择，先由议程决定"这一步要推动什么"（让队伍成长、强制考验、对照实验、瓶颈试炼、终局……），再进入下面的出题流程决定手段。**每个决定都附一段隐藏的"主神理由"**，写进存档。它既用来调试，也是智者可以推理的对象：楚轩、萧宏律能从片的选择里推出主神的意图（"它不会把弱队扔进死神来了，除非……"）。

**原剧情的偏离**：玩家改变了原著的走向时，主神按同一套议程逻辑应对。例：如果张杰提早完成了考验，异常就提早解除，后面几部片的难度随之回落；如果詹岚没在度假时被催眠，主神可能换别的方式去"清除拖累"。

**第一步：队伍画像**。主神看到的不是"真实战力"，而是**评价**：完成过的片的难度 + 兑换属性的强弱，**自创技能和基因锁不计入**（L7866、L21838）。画像拆成几个维度，每个维度既有"评价值"也有"真实值"：

| 维度 | 含义 | 例子 |
|---|---|---|
| 正面战力 | 打得过多强的东西 | 高级气功、伯爵血统 |
| 机动 | 能多快、多远地移动 | 轻功、绿魔滑板、飞行 |
| 信息 | 知道多少 | 剧情知识、精神力扫描、智者推理 |
| 科技依赖 | 有多少战力来自科技武器 | 高斯狙击、核弹 |
| 超自然应对 | 能不能对付灵体、诅咒 | 灵类子弹、纳戒、红炎 |
| 群体破坏 | 有没有清场、灭城能力 | 死神军团、魔动炮 |
| 精神韧性 | 心魔、心灵漏洞有多大 | 张恒的懦弱、霸王的战友 |
| 保护能力 | 能不能护住脆弱目标 | 护盾、龙晶项链、医疗 |
| 成长瓶颈 | 下一步卡在哪 | 第四阶心魔、沉睡的队友、缺精神力控制者 |
| 道德倾向 | 主神从罪恶感和满足感判定的阵营（L20230） | 善 / 中立 / 恶 |

**第二步：约束库**。每条约束都是一份数据：施压维度、参数、适用条件、失效条件、原著出处。

| 约束 | 施压维度 | 参数如何随队伍缩放 | 失效（不再出现）的条件 |
|---|---|---|---|
| 绑定剧情人物 | 机动、绑定剧情 | 半径取"队伍在剧情节奏下勉强跟得上"的距离（普通人 100 米，开锁者 5000 米） | 机动高到半径失去意义 → 改用保护或区域限制 |
| 保护目标 | 保护能力 | 目标越脆弱、越"免疫你的长处"越难 | — |
| 取消倒计时 / 必杀目标 | 防"躲" | 用在上一部靠躲过关之后 | — |
| 区域限制 | 机动 | 时长和范围 | — |
| 禁飞 / 禁载具 | 机动 | — | 队伍不靠飞行时不出 |
| 科技无效 | 科技依赖 | 无效比例 | 科技依赖低时不出 |
| 屏蔽扫描 | 信息 | 屏蔽范围 | 没有精神力控制者时不出 |
| 禁止打听或泄露剧情 | 信息 | 每句扣分额 | — |
| 剥夺强化 | 正面战力（买来的那部分） | 剥夺范围 | — |
| 动态进化 | 正面战力 | 触发阈值 | — |
| 精神攻击 / 心魔场景 | 精神韧性 | 针对每个人的心灵漏洞 | 心魔都过了以后少出 |
| 打不着的敌人 | 正面战力 | 事件频率 | — |
| 敌对轮回小队 | 全面 | 对手评价 ≈ 本队评价 ± 一档 | 累计开锁者不到 3 名时不出（石碑规则） |
| 禁大范围武器 | 群体破坏 | — | 没有灭城武器时不出 |
| 后期追加任务 | 防"躲" | 剩余时间比例 | — |

**第三步：选约束、定难度**。主神按画像挑 1~3 条约束，**优先压队伍最强、最依赖的维度**，再叠一条指向成长瓶颈的"机会"（支线、钥匙型新人、剧情物品）。目标是让主线的预计全灭率落在一个区间里，并且**一定留一条轻松解法**（原则 6）。原剧情模式下，主神照原著出题。这套模型拿原著做标定：用当时的队伍画像跑一遍，应该能得到和原著相近的约束（新人 → 100 米；三名开锁者 → 5000 米 + 团战……）。

**第四步：主神"看不到"的地方是玩家的战略空间**。评价不算自创技能和基因锁，所以花时间练自创技能、冲基因锁，能让真实战力高于主神的估计：同样的奖励，你拿得更安全。这正是原著里郑吒走的路线。

## 二、奖励点数与支线剧情：和相对难度挂钩

### 2.1 原著证据：同一种怪，队伍越强给得越少
| 怪物 | 早期 | 后期 | 出处 |
|---|---|---|---|
| 爬行者 | 生化危机一：100 点/只（队伍是普通人） | 生化危机二：50 点/只；偷袭生化：巨大爬行者 25 点/只 | L50、L6524、L13099 |
| 异形 | 异形一：500 点/只 | 异形4：100 点/只（个体还更强） | L1510、L5760 |
| 丧尸 / 虫子 | 生化危机一：10 只丧尸 = 1 点 | 星河战队：100 只虫 = 1 点 | L50、s09 |
| 支线等级 | 生化危机一：救下马修 = B 级 | 后期只有"威胁生命"的事才给 B（B 的全灭率约 80%） | L8908 |

另外：每部片固定 1000 点不变；主神"不会给能随意刷分的片"（s21）；"威胁等于奖励"（L8025）。

### 2.2 游戏规则
- **击杀奖励** = 怪物基础价 × 相对威胁，相对威胁 = 怪物威胁 ÷ 击杀者（或出手队伍）的评价战力。相对威胁低于约 0.05 时，奖励归零——"像玩一样"的杀戮不给分。用原著数字标定曲线：爬行者 100 → 50 → 25。
- **支线等级相对化**：支线等级 = 这支队伍完成它的**预计全灭率**（D 简单 … C 困难 … B 约 80% … 双B ≥ 90% … A 以上影响整个世界）。同一个"杀伽椰子"，对咒怨时期的队伍是 B，对后期队伍可能只是 D，甚至不再作为支线出现。
- **固定项不随难度变**：存活 1000 点、讲解规则 +100，以及各种扣分（杀新人 −1000、泄密 −10）。
- **改变剧情**：奖励和扣分都随"剧情偏移量"放大（支线规律一）。
- **评价的变化**（楚轩的推理，L8003~8006、L21846）：
  - 主神把队伍"固定在即将生和即将死的边缘"（L8003）：每部片都按"差一点就团灭"来安排。
  - 活过一部本该团灭的片、损失又小，评价加一分（印洲战、死神来了2、异形4 都是这样）。
  - 队长死亡扣分。
  - **团灭清零**：所有人都死了（中途靠重生十字章复活的也算死过），评价归零，回到普通小队的难度；经历过的片的记录也消失，可以重进同一部片。
  - 评价越高，片越少越凶，团战对手越强（L16676）；评价超过特殊小队时，主神会安排和它们对抗来验证。
  - 不死人会让评价上升（s16），牺牲新人能让评价略降——这是原著里真实存在的道德选择。

## 三、小队构成：选人机制与天赋

### 3.1 原著证据：主神不选没用的人
- 楚轩："「主神」也在选择各方面的人才……从真正有能力的人到家庭主妇……这才将各种范围的人都拉了进来"（L1572）。
- 郑吒在心魔破碎后才明白"主神为什么会挑选现实世界中的失败者……因为正是需要失败啊"（L22892）。被选中的人往往对现实失望，心里有一道伤口——它既是心魔，也是突破口。
- 几乎每个活下来的人都有一项**当时看不出、条件到了才发挥的特质**：

| 人物 | 现实背景 | 隐藏特质 | 发挥条件 |
|---|---|---|---|
| 郑吒 | 白领，失去青梅竹马 | 远古"死敌"基因（隔代遗传）；熟知电影剧情 | 濒死 → 基因锁；心魔破碎 → 第四阶中级 |
| 楚轩 | IQ220 的大校科研人员 | 第一代基因改造人，无痛觉、无感情；极限推理 | 一开始就能用，但"感情"直到最终一战才觉醒 |
| 詹岚 | 作家 | 万中无一的精神力天赋（精神力只有两百多就能学精神系技能） | 兑换精神系技能 |
| 萧宏律 | 12 岁、被精神病院研究的孩子 | 能看见死气；"凡人智慧的顶点" | 被收为成员、给他布局的机会 |
| 齐腾一 | 盗墓文物鉴定师 | 古文字天赋 | 下一部恰好是神鬼传奇，他能免费读亡灵圣经 |
| 张恒 | 弓箭替补选手，曾在流氓面前丢下恋人 | 什么弓到他手里都能发挥威力 | 兑换精灵射手血统；克服懦弱后连射七矢 |
| 程啸 | 中医世家军医，母亲是蛊教教主 | 毒血、蛊、古武、外科手术 | 团队重伤需要手术时 |
| 王侠 | 特种部队侦察兵 | 爆破与陷阱 → 炸弹支配者 | 兑换妖力系强化 |
| 罗甘道 | 高三学生，爱玩街机 | 驾驶直觉 | 得到机甲 |
| 零点 | 不笑的杀手 | 狙击直觉 → 点线魔眼 | 兑换瞳术 |
| 朱雯 | 天生闭眼的新人 | 睁眼能看见谁随时会死 | 没来得及发挥就死了 |
| 刘郁 | 读过很多梦境类书的富家子 | 梦境理论 → 召唤卡 | 猛鬼街里提出"两个支点"理论 |

还有一个规律：**新人的特质常常正好是下一部片需要的钥匙**（齐腾一的古文字 → 神鬼传奇；程啸的手术 → 异形4 之后的重伤；刘郁的梦境知识 → 猛鬼街）。这和出题原则 6 是同一件事：主神一定留一条解法，有时就是一个人。

### 3.2 游戏规则：每个轮回者都有特色
每个角色（原著人物和随机新人都一样）由下面几部分组成：
- **现实背景**：职业、经历、技能（司机、律师、作家、军人、程序员……），决定初始能力和对话。
- **天赋**（隐藏）：一项和背景有关、超出常人的潜质，带**发挥条件**（遇到某种危机、兑换到契合的强化、被队友点破、跨过心魔）。没满足条件就是"发挥不出来"。
- **心魔 / 心灵漏洞**：那道伤口。决定恐惧崩溃时的表现，也是第四阶心魔关的内容。克服心魔会让天赋大幅增强（原著："心灵漏洞越大，突破后实力提升越多"）。
- **潜力**：觉醒概率和成长上限。
- **性格**：AI 接管时的行为依据（服从、怯懦、冷血、热血……）。

**天赋与兑换契合**：契合的兑换项更便宜、发挥率更高，或者绕开素质门槛（詹岚精神力不到 3000 也能学精神系技能）。

**新人生成规则**（沙盒与原剧情的随机新人共用）：
1. 主神按队伍画像补人：优先补队伍缺的角色（精神力、智者、医疗、火力……）。
2. 每批新人里至少有一个**钥匙型天赋**，和当前片或下一部片的解法相关。
3. 每个新人都有特色，但大部分人的发挥条件很苛刻——"没有没用的人，只有没发挥出来的人"。新人一死，潜力就永远没了，于是保护新人还是牺牲新人成为真实的取舍。

## 四、兑换体系：不局限于原著，要大量

### 4.1 原则
原著自己说可兑换物"至少有数百万件以上"（L5642），而且大量取材于其他作品（蜘蛛侠、海贼王的果实、JOJO 的石鬼面、龙与地下城的魔网、圣斗士的沙加、北斗神拳的南斗水鸟拳、游戏王的召唤卡、EVA、高达和超时空要塞、型月的直死魔眼与 EXCALIBUR、全金属狂潮的 λ-drive、蜀山……）。所以游戏的兑换体系可以同样**广泛取材于各类作品、神话和科幻设定**，只要守住原著的经济规律。

### 4.2 分类结构（四大类 → 子类 → 系列 → 等级链）
| 大类 | 子类（系列举例，每个系列有 D→S 的等级链） |
|---|---|
| 科技类 | 枪械（实弹、能量、电磁、高斯、等离子）、爆炸物、重武器、动力装甲、机甲与载具、无人机、护盾、侦察通讯、医疗科技、基因药剂、生化改造、零件与图纸 |
| 魔法传说类 | 近战神兵、远程神兵、法杖法器、卷轴与符箓、魔法护具、可进化武器、能量石与魔法材料、召唤媒介、修真法宝 |
| 辅助类（强化） | 血统（血族、狼人、精灵、龙族、巨人、天使、恶魔、妖怪……）、体质（魔网、查克拉、斗气……）、内功与武学（各门派、各级）、精神系、瞳术、果实系（自然 / 动物 / 超人）、基因进化、修真功法、异能 |
| 辅助类（道具） | 药品丹药、空间装备、通讯标记、解毒与净化、复活与保命道具、阵法材料 |
| 娱乐类 | 造人、生活天数、物资与奢侈品、旅行、伴侣与宠物、信息与情报（新增） |

### 4.3 规模目标
| 阶段 | 条目数 | 来源 |
|---|---|---|
| 切片（SP1） | 约 200 条，覆盖 D~B | 原著首批清单 + 同档扩充 |
| 完整版（SP2） | 2000 条以上，覆盖 D~双S | 按系列 × 等级批量设计（AI 辅助生成数据，人工审核） |
| 长尾 | 不限 | 玩家向主神"许愿"，主神 AI 现场生成（见 5.2），由规则引擎定价和校验后写入本存档的目录 |

### 4.4 让"大量"可控：效果积木 + 定价公式
- 每个兑换项不是一段描述，而是一组**效果积木**：属性加成、技能、能量池、被动触发（受击时、击杀时、低血时）、状态、标签（科技 / 魔法 / 灵类 / 因果……）、门槛（前置、素质、能量类型）、副作用（变异风险、心魔、折寿、宇宙排斥）。规则引擎能直接执行积木，所以 AI 生成的新条目也是"真能用"的。
- **定价公式**：由效果积木算出强度分 → 决定支线等级和点数，并遵守原著规律：
  - 10 点 = 1 属性点；
  - 无限弹药版约为有限版的 20 倍以上；
  - 同等威力下，魔法传说类约为科技类的 2 倍；
  - 高级需要同系低级作前置；同时持有两种血统有 70% 变异风险；
  - 有副作用的打折；
  - 显示原著式的评价分（68~197）。
- **原著价格是锚点**：公式必须把原著出现过的价格算对，例如血族伯爵 = 3000 + B、高斯狙击 = 5000 + D。

## 五、主神与 NPC 由 AI 接管

### 5.1 原则：AI 提议，规则引擎裁决
- 数值、合法性、生死由确定性的**规则引擎**负责；AI 负责**判断、对话、创作**。
- AI 不直接改游戏状态，只输出结构化的"意图"（说一句话、从合法行动里选一个、提议一条任务约束、提议一个兑换项），由引擎校验后执行。
- 这样能保证存档一致、规则不被 AI 说乱，也能在没网时退回脚本。

### 5.2 主神 AI 的职责
| 职责 | 做法 | 约束 |
|---|---|---|
| 问答 | 根据"主神规则库"回答规则问题 | 秘密分级，按剧情进度解锁；不该说的拒绝回答或不回应（原著风格） |
| 出题导演 | 读队伍画像，从约束库里挑约束、定参数、放置支线和钥匙；原剧情模式下照原著剧本 | 必须满足出题八原则；引擎估算全灭率，不在区间内就打回重出；必须留一条轻松解法 |
| 结算 | 逐条宣读奖励、扣分 | 数字由引擎算，AI 只负责宣读 |
| 兑换许愿 | 玩家用自然语言描述想要的东西，AI 在效果积木里拼出方案 | 引擎定价、校验平衡上限；超出主神权限就拒绝 |
| 片中干预 | 战力过临界值时进化怪物、后期追加任务、屏蔽扫描 | 从约束库里选，引擎执行 |

### 5.3 NPC AI 的职责
| 对象 | AI 负责 | 规则引擎负责 |
|---|---|---|
| 剧情人物（马修、艾丽丝……） | 按人设对玩家的话和行为作出反应：能不能说服、会不会起疑、信不信你 | 剧情时钟、剧情惯性、生死 |
| 队友与新人 | 性格驱动的发言、投票、服从或抗命、崩溃时怎么表现；扮演个人模式时替其他队员做决策 | 恐惧、信任数值，合法行动列表 |
| 其他轮回小队 | 对手队长的策略：谈判、结盟、欺骗、伏击 | 团战积分、"势" |
| 战斗中的敌人 | 重要敌人开战时由 AI 定"战术方针" | 逐回合行动用确定性的效用 AI（快，不依赖网络） |

### 5.4 工程要点
- **模型分档**：出题、许愿、对手队长这类低频高价值的决策用强模型；NPC 日常对话用快而便宜的模型。
- **上下文**：一份"世界设定库"（本文、全书摘要、机制百科、主神功能清单）加当前存档摘要，静态部分用提示缓存降低成本。
- **记忆**：每个重要 NPC 有一份记忆摘要，随存档保存。
- **延迟**：对话流式输出；出题这类重活放在休整期或转场时预先生成。
- **离线兜底**：没有网络时，原剧情模式退回原著脚本台词，沙盒退回规则化的出题器。
- **可复现**：AI 的输出写进存档，读档不会重新调用。

## 六、养成体系：不止"花点数兑换"

### 6.1 原著里的成长途径
原著里的人变强，靠的远不止兑换：
- **锻炼**："一个人的素质点是随着他锻炼的多少而不停改变的"（张杰，L641）；零点、赵樱空、张恒"每天每夜锻炼到受伤，接着主神处全面修复了又开始锻炼"（L15948）。
- **能量自修**：内力会自行增长；混元一气功要约 30 天提纯；真元力要花 90 天在魔戒世界里凝炼。
- **熟练**：A 级以上兑换来的"只是心法"；兑换后要靠对练熟悉。
- **实战**：战斗意识差、全靠兑换的人，遇到自创技能者会被"打回原形"（L12234）。
- **自创技能**：爆炸 → 毁灭 → 瞬间毁灭 → 洪荒；闪灵真空波；N 矢爆裂箭；风的协同；狂战士。自创技能 100% 发挥，而且**不计入主神评价**。
- **突破**：基因锁、心魔、天赋觉醒；"心灵漏洞越大，突破后提升越多"。
- **器物**：可进化武器（C → B → A → 双A）、滴血认主、楚轩的改造与自制。
- **羁绊**：心灵锁链共享视野；零点 + 齐腾一的曲线狙击；张恒和勒苟拉斯合射；詹岚链接、齐腾一计算、林俊天具现、王侠控爆、零点射击的五人组合（最终一战的瞬间黑洞）。

### 6.2 游戏的十条成长线
| 成长线 | 怎么涨 | 花什么 | 计入主神评价？ |
|---|---|---|---|
| 兑换强化 | 主神兑换 | 点数 + 支线 | **计入**（评价↑ → 难度↑、奖励↓） |
| 锻炼 | 休整期训练；"练到受伤再修复"的高强度循环收益更大 | 休整天数（+ 修复费） | 不计入 |
| 能量修炼 | 内力、血族能量自然增长；提纯、凝炼是长周期进度条 | 天数，或花点数买"天数外"的世界时间 | 不计入 |
| 熟练度 | 训练和实战使用新技能、新武器 | 天数、战斗 | 不计入 |
| 战斗意识 | 真实的高危战斗（越接近死亡收益越大） | 风险 | 不计入 |
| 领悟与自创技能 | 在极限状态下使用技能、观察他人、模拟、被点拨，攒"领悟"；满了触发**顿悟** | 风险、机缘 | **不计入** |
| 基因锁与心魔 | 濒死觉醒；第四阶心魔关 | 风险、剧情 | 不计入 |
| 天赋觉醒 | 满足发挥条件 | 机缘 | 不计入 |
| 器物 | 进化（追加支线）、认主、改造、研究剧情物品 | 支线、材料、天数、人才 | 兑换部分计入 |
| 羁绊 | 共同作战、救命、共享秘密 | 关系 | 不计入 |

**核心取舍**：兑换是"看得见的成长"，快，但主神看得见，会抬高难度、压低奖励；其他九条是"看不见的成长"，慢、要冒险，但真实战力会超过主神的估计。这正是原著里郑吒的路线（自创技能、基因锁），也是玩家最重要的长期策略。

### 6.3 自创技能的机制
- **领悟值**：每个角色按自己的天赋方向积累。来源包括：把某项技能用到极限（能量见底、濒死时用）、亲眼看到别人的招式、用基因锁第三阶模拟别人、被高手点拨、心魔突破。
- **顿悟**：领悟满了又满足前置时触发。AI 用这个角色**已经拥有的效果积木**拼出一个新技能，并给它起名、写描述，例如郑吒的"内力 + 血族能量同时爆发"= 爆炸。引擎按"组件强度 × 协同系数"校验预算，并强制带上代价（自伤、后遗症、冷却）。
- **进化链**：自创技能可以继续顿悟升级（爆炸 → 毁灭 → 瞬间毁灭）。
- **边界**：第四阶中级之前，只能组合已有的东西；第四阶中级以后，才能"创造"新的效果（原著："中级可进化改变基因并创造技能"）。
- **心灵之光**：到第四阶中级时，按角色的心理和天赋生成个人化的心灵之光（郑吒的潜龙变白炎、复制体的戾炎、赵樱空的湮灭、罗甘道的 AT 力场、张恒的生命力自愈）。

### 6.4 队伍层面的成长
- **团队章程**（见第八节）。
- **工坊科技**：需要科技人才；用材料 + 图纸低价制造，研究剧情物品（闪光石一颗要读几个月）。
- **势力**：在旧片世界培植的势力，如黑衣一族的五万人基地、洛汗的"幽灵之蹄"骑兵，回访时能提供支援。
- **情报库**：经历过的世界记录、敌人图鉴、规则百科。
- **纪念石壁**：阵亡者名单，是士气和心魔事件的来源。

### 7.2 游戏设计
- **造物是完整的 AI 角色**：人设来自制造时的设定（外貌、年龄、性格、经验）。如果是"按记忆复制"某个人，玩家写下对这个人的记忆，AI 以此为人设种子——原著里主神说过，萝丽的记忆就来自郑吒对她的记忆。
- **住在制造者的房间里**，有自己的心情和愿望：担心出征的人、想一起去、想被需要、想去看看现实世界，也会吃醋、会孤独。
- **陪伴行动**（休整期，耗天数）：聊天、约会、一起训练、教她技能、带她度假或回现实。对话由 AI 驱动，带长期记忆。
- **关系数值**：亲密、依赖、安心。
- **对制造者的影响**：
  - 休整期恐惧恢复更快；
  - 心魔检定时，她是"锚"，提供加成；
  - 但她也是软肋：她受伤或死亡时，制造者恐惧暴涨，可能崩溃，可能**黑化**（偏向王者之道，复制体的路线），也可能迎来"情绪化的奇迹"突破。
- **成长**：主神强化（花点数）、有限的训练、穿戴护具（原著的防护盾、玉佩）、学会后勤类专长（医疗、烹饪、情报、驾驶），在远征里占一个支援位。另有一条黑暗选项：用 TBD 把她改成追踪者，战力大涨、意识空白。这是一个道德抉择。
- **入片义务**：有队长之后，造物必须一起进片（变成要保护的对象），或者每部片花 1 个 D 级支线赎身——持续的成本。
- **死亡与重造**：造物被杀后，可以花 500 点按制造者的记忆重造，但新造物**只有制造者记得的那部分**，她自己的私人记忆没了。这是游戏规则，从原著"记忆来自制造者"推出来。
- **同一框架也用于**：带入队伍的剧情人物（伊莫顿、安苏娜，通过"携带手表"）、剧情生物（黑龙、骷髅梦魇，作为宠物或坐骑）。

### 8.2 游戏设计
**关系网**（每两人之间）：信任、好感、敬畏、怨恨，外加标记（恋慕、仇敌、师徒、战友、旧识）。由事件改变：救命、并肩作战、意见被采纳会加分；被当诱饵、分配不公、见死不救、违背承诺会扣分。

**个人倾向**：忠诚、野心、道德、求生欲、理念（伙伴之道 / 利益至上 / 强者为尊 / 只顾自己）、心魔。

**团队层面**：
- **凝聚力**：由关系网汇总。
- **派系**：关系网里自然形成的小圈子。
- **团队文化**：由队长理念、团队章程、过往经历决定。

**凝聚力的作用**：
- **服从**：扮演整队时，信任低的成员会转为 AI 控制，可能抗命。
- **投票结果**。
- **合击技和心灵锁链的效果**。
- **救援意愿**：AI 队友愿不愿意冒险救你。
- **恐惧传染**：凝聚力越低，一个人崩溃越容易带垮一片。
- **赠予意愿**：愿不愿意把点数、支线给别人。

**冲突升级阶梯**（引擎按阈值推进，AI 负责具体表现）：
1. 不满
2. 顶撞
3. 抗命
4. 擅自行动
5. 私藏或偷窃（剧情物品、补给）
6. 叛逃或转队（投靠别的队，或签"地狱契约"）
7. 背刺、谋杀（主神照扣杀队员的 −1000 点）
8. 内斗团灭

**常见导火索**（来自原著）：诱饵和牺牲的决定、点数与剧情物品的分配、队长的冷血决策（楚轩用氢弹炸死数十万美军）、杀害无辜、理念冲突、感情纠葛、新老矛盾、旧怨（赵樱空与赵缀空）、民族仇恨、被控制或卧底、复制体与引导者混在队里。

**团队章程**（可编辑的"中洲五条"，像政策卡一样）：新人是否要投票入队、资源统一分配还是各管各、剧情物品由谁保管（改规则要七成同意）、保护优先级、允不允许牺牲新人、内斗惩罚（例："三次警告无效全员追杀"）。每条都会改变凝聚力、效率和风险。比如"赵缀空式"的开局先杀新人：立刻背负负分，但消除了背叛风险，也会让整支队伍的文化滑向"强者为尊"。

**队长的威信**：威信 = 敬畏 × 合法性（被引导者认可）。牺牲谁、用谁当诱饵，会扣掉相关成员的信任，除非事先说服或事后补偿。楚轩式的理性领导和郑吒式的情义领导，会走出不同的凝聚力曲线。

**其他轮回小队**：每支 AI 队伍都有自己的文化和凝聚力。
- 东美洲：强者为尊、团战先杀新人。
- 印洲：涣散，宁可自己杀自己人也不让敌人得分。
- 南炎洲：两派。
- 森洲、西海：圈养新人。
- 东海：民族主义加内讧。
- 恶魔：强者自由、个人宣言、队员是棋子。
- 天神：用谎言统治。

凝聚力低的队伍可以被**挑拨、收买、招降、换情报**；凝聚力高的队伍会死战到底。原著里，郑吒在神鬼传奇赌印洲队不团结，楚轩在星河战队让南炎洲的士兵倒戈，都是这个机制。

**特殊身份**：新人里可能混着别队的卧底（昊天）、主神的引导者、被精神控制的人。

**扮演个人模式**：社交本身就是核心玩法。你不一定是队长，要拉票、结派、劝说，必要时也可以背叛。

## 九、智谋线：让楚轩这类人不可替代

### 9.1 问题
之前的设计里，玩家是唯一的决策者，战斗交给引擎，智力只给命中和闪避一点加成——楚轩就成了一个拿着两把枪的普通单位。原著恰恰相反：中洲队一次次以弱胜强，靠的主要是楚轩、萧宏律；而他们几乎不兑换强化（楚轩很长时间"无强化"），主神的评价根本看不见这份力量。**智谋是全书最大的"隐藏战力"。**

### 9.2 原著里智者具体做了什么
| 作用 | 例子 |
|---|---|
| **推理，揭示隐藏信息** | 楚轩：异形一推出有皇后、提出基因锁理论；咒怨里从"七天"推出七波；侏罗纪推出真正的危险是古代昆虫、第三条支线是改变未来。萧宏律：从联络器光点速度骤降看穿新人被控；猛鬼街提出"三个世界"；从一句"复制体来一趟嘛"看穿天神小队在借刀杀人 |
| **发现规则和漏洞** | 楚轩：第一个造人名额应该造保镖、零件和图纸能绕开支线、"记录"能回旧片和现实（L1556~1597）；支线三规律（L8896）；冷藏尸体能省 1000 点复活费；让死去的新人身份复活霸王、王侠免费 |
| **计算概率与风险** | "杀掉皇后的成功率……约在三成左右，已经很好了"（L1366）；"成功几率小于五成的我拒绝参与"（L9906）；"全员活下去的几率在七成以上"（L11236）；"变数几率 87%"（s22） |
| **布局** | 异形一的诱饵计划；星河战队杀光随队士兵以隐藏身份、"造势"、七存一作战；魔戒的假死局；变形金刚的氢弹诱饵；完美风暴故意"示弱"让赵樱空被俘；最终一战"以乱制胜"、王对王、兵对兵 |
| **对弈** | "以局破局"（L11242）对尼奥斯的"寄生虫局"；和亚当的阳谋互相算计（"既生瑜，何生亮"）；和复制体楚轩以封神榜对东皇钟 |
| **欺骗（对敌，也对自己人）** | "我骗你的"——郑吒的不满是他"每次都在算计我之后轻描淡写的说一句我骗你的"（L21864） |
| **情报与"势"** | 星河战队的舆论战、象形文字暗号；神话惊程"以力破巧"夺取上海情报网、和蒋介石结盟 |
| **科技研发** | 联络器、绿魔滑板、充能秘银戒、电浆炸弹、魔动炮、意识连接头盔、修真虚拟幻境、黄巾力士试作型、超级病毒；破译符号铭文、闪光石 |
| **战场指挥** | 用心灵锁链倒数"停！投！"；分配主攻、诱饵、狙击；用枪斗术预判弹道 |

对手那边也一样：尼奥斯（"凡人智慧的极限"）、亚当（引导真实的谎言、补全计划）、复制体楚轩（封神榜、把队员当棋子）。

### 9.3 设计：智力是一种"能力"，不是属性加成
**原则：智者的价值 = 信息 + 选项 + 概率。** 没有智者，玩家只能看到零散的线索、只有很少的行动选项、看不到成功率；有了智者，迷雾被拨开，计策变多，每个决定都带着估算出的胜率。玩家仍然是最终拍板的人，但"能想到什么、能知道什么"取决于队里有谁。

**A. 信息迷雾与推理**
- 每部片都藏着大量**隐藏事实**：敌人的弱点、支线的触发条件、主神任务里的文字陷阱、剧情的真实走向、对手队伍的计划、队伍里的卧底。
- 玩家通过探索、对话、观察、原著知识得到**线索**。
- 智者可以花时间做**推理**，把线索转成**推论**并给出可信度（"存在皇后，可信度七成"）。准确度取决于智力、线索数量、领域熟悉度（生物、物理、符文、修真、军事、心理）和天赋。
- 推论**可能出错**；两个智者可以互相校验（萧宏律与楚轩）。

**B. 规则发现**
- 引擎里存在一层**隐藏规则和漏洞**：造人当保镖、零件绕开支线、"记录"可回旧片、冷藏尸体省钱、新人复活免费、复活集资和赠予的关系、自创技能不计评价、牺牲新人能降评价、"主神不给必死任务，所以一定有解"、各种文字陷阱……
- 这些在被**智者通过实验或推理发现之前，机制上是锁住的**，比如零件图纸页要楚轩推出来才会开放。
- 发现后写进规则百科，并带来真实的好处：更便宜的路线、新的兑换页、新策略。这让智者在"局外"也持续产生价值。

**C. 计策与布局**
- 在地点图和剧情时钟之上有一层**计划层**。计划由**计策积木**组成：诱饵、伏击、分兵、佯攻、示弱、情报欺骗、借刀杀人、制造混乱、斩首、预设撤退路线、布置陷阱、造势与舆论、夺取剧情势力……
- 每块积木都有角色分配、前置条件、耗时、风险和道德代价。
- **智者提出计划**：引擎的规划器真正去搜索可行方案，搜索的深度和质量由智者的智力和掌握的信息决定；AI 再用这个人的口吻讲出来（楚轩冷淡、话少、经常不讲全；萧宏律会拔着头发解释）。
- 计划执行后会改变战斗的初始条件（先手、敌人被分割、陷阱伤害、援军、敌方士气），可以直接绕开战斗，也可以改写剧情。
- **成功率**只有队里有智者时才显示，精度随智力提高。

**D. 智者对弈**
- 敌方智者（尼奥斯、亚当、复制体楚轩）也用同一个规划器布局，用的是他们自己的智力和情报。
- 每个计划都带着"对敌人的假设"。对方的实际行动违背了你的假设，你的计划就会出问题。
- 智力差和情报差决定谁"看得更深一层"。欺骗类积木（示弱、假死、空弹头导弹）专门往对方脑子里塞错误假设。
- 团战因此首先是一场**智者之间的较量**，"以局破局"可以真实地发生。

**E. 战场指挥**
- 小队里有智者（或者通过心灵锁链、通讯与智者相连）时，CTB 时间轴上会显示**敌人下一步的意图**，准确率随智力提高。
- 智者可以给队员下**预案**（"它扑向詹岚时，你立刻开枪"）这类条件指令，也能协调合击（倒数投掷）。
- 战前可以布置陷阱、选择地形。楚轩自己的枪斗术也以"预判"为核心。

**F. 科技研发**
- 需要智者 + 材料 + 时间 + 知识来源（剧情物品、遗迹、破译成果）。
- 研究树涵盖：破译（符号铭文、闪光石）、发明（联络器、滑板、储能戒、魔动炮……）、改造现有装备。
- AI 用研究得到的知识，在效果积木里提出发明方案，引擎校验。
- 自造的科技能绕开支线门槛，而且**大部分不计入主神评价**（原著里中洲队在修真科技上"已经超脱出主神的控制"）。

**G. 情报网与"势"**
- 在电影世界里，智者能建立情报网，操纵舆论，在军方、黑帮、政府里取得地位，与剧情势力谈判。
- 这些都是地图层的长期行动，智力决定效率。

**H. 智者自己的成长**
- 知识领域（越研究越熟）、情报积累、布局的成败经验、天赋（楚轩：第一代基因改造人的超算大脑；萧宏律：死气感知）。
- 第四阶：楚轩的信念之力（越理性越难发动，代价是寿命）。
- 心魔：楚轩的心魔是"感情"，到最终一战才落泪。

**I. 在不同模式里**
- **扮演整队**：智者就是你的**参谋部**。智者越多、越强，你能看到的信息、能选的计划、能估算的胜率就越多。
- **扮演个人（例如郑吒）**：楚轩由 AI 接管，自己布局，可能**瞒着你**牺牲别人，事后一句"我骗你的"。信不信他、拦不拦他，直接连到内斗系统（郑吒两次和他决裂）。
- **扮演楚轩**：推理、布局、研发的工具全部开放，但战斗力很弱，要靠别人保护。

**J. 道德张力**
- 规划器追求的是存活率和收益，最优解里常常包含牺牲（诱饵、氢弹炸死数十万美军）。执行这种计划会扣队员的信任，于是"情义之道"和"理性之道"的冲突真正落到了数字上。

**K. 主神看不见智谋**
- 智者几乎不兑换，评价很低，却是全队最大的战力乘数。这和"看不见的成长"（第六节）是同一条逻辑。

### 9.4 工程要点
- 引擎需要一个**信息模型**：每条事实对每支队伍有"未知 / 有线索 / 推论（带可信度）/ 已确认"几种状态。
- 引擎需要一个**规划器**：在计策积木上做搜索，用模拟估算成功率；智力决定搜索深度和估算噪声。
- 敌人 AI 必须**提前确定意图**，这样才能被"看见"。
- AI 只负责用人物口吻讲出规划器的结果，以及它是否要隐瞒；计划好不好由引擎保证，不依赖大模型"临场发挥"有多聪明。

## 十、特殊小队的逻辑：主神的进化实验

### 10.1 原著依据
- 主神给队长的信息：恶魔小队是"将各个小队里有实力者的基因复制了，拿到这个小队里组合起来"，"也是为了试试什么样的情况更适合进化"；天神小队是"在某人成为队长时，询问其是否加入……全是各个小队的最强者……也是「主神」试验进化的其中一种可能性"（L5619）。
- 萧宏律的对比：天神小队成立时每个成员都已解开基因锁二阶，起点更高；恶魔小队的成员是"别的队伍中最具有潜藏实力和成长力量的角色"，成长率高得多（L6345）。
- 复制的时机：复制体郑吒说"我是你……生化危机一后复制的……具体时间是你在制造了她之后……之前的你并没有太大的潜力……但是制造了她之后，你的生存潜力却突然提高了许多"，复制的内容"连同你的奖励点数，强化属性兑换物品，甚至是制造的人"（L7310）。
- 恶魔小队内部："进入恶魔轮回小队，就必须要有恶魔一样的心肠"；当时 17 人里十一个白种人复制体把其他人当作"会走的猪"，逼他们为核心人物提供点数和支线；复制体的萝丽被他们凌辱、分尸（L7311~7313）。赵缀空对他说"感情是负累，如果我的器量不够，那就死掉好了"（L7314）。复制体隐瞒自己完成的支线，在铁血战士一里杀光了所有欺辱过他的人，开到第三阶，继承了队长权力，进化到第四阶初级（L7315~7317）。
- 天神邀请的代价：南炎洲队的第一任队长去了天神小队；只要他还活着，第二任队长"只具备主神信息查询资格"，不升阶、不被邀请，南炎洲队从此一直很弱（L11183）。两支都被队长抛弃的弱队在魔戒里相遇，和平共处、各取所需（L11185）。
- 后期：天神小队联络各队组成"天使联盟"，对抗"越来越疯狂的恶魔轮回小队"（L20367）。

### 10.2 三种环境 = 三组实验
| 组别 | 条件 | 主神想验证什么 | 原著里的结果 |
|---|---|---|---|
| 普通队伍（如中洲队） | 引导者 → 队长 → 成长窗口 → 团战；成员有羁绊 | 伙伴之道、靠团队成长能走多远 | 中洲队最终胜出 |
| 恶魔轮回小队 | 复制各队潜力最高的人，在"恶魔心肠"的环境里弱肉强食 | 抛弃感情、只求力量能走多远 | 成长最快，最终一战失败；复制体郑吒临终说想要"伙伴和心爱的女人" |
| 天神小队 | 把各队已开锁的队长集中起来 | 精英集中能走多远 | 起点最高；亚当用谎言统治，罗应龙叛逃；补全计划失败 |

**同一个人，两种环境**：复制体和主体本是同一个人，只因为被放进不同环境，走上了相反的路（郑吒："应该是绝对会变成眼前这个疯狂的复制体吧"，L7317）。最终一战的"王对王"，就是这场对照实验的结论。

**天神邀请也是一道考题**：接受，就是拿个人的生存换掉整支队伍的未来——原队失去队长，从头再来，往往从此衰落（南炎洲队）。郑吒拒绝，理由是"选择同意的话，这就是一种背叛"（L5626）。

### 10.3 游戏设计
- **主神维护整个轮回世界的状态**：17 支普通队伍加两支特殊小队，每支都有课程阶段、队长、开锁者、文化、凝聚力，在后台以"粗粒度"推进（谁团灭了、谁的队长去了天神、谁被复制）。队长权限能看到其中一部分，作为"新闻"。
- **恶魔小队是镜像生成器**：
  - 玩家的角色出现**潜力突升**（造人、凭自身属性开锁、心魔突破、自创技能顿悟……）时，主神可能给他做一份快照：属性、兑换物、点数、造物，复制进恶魔小队。
  - 复制体在后台过一段平行人生：在恶魔小队的文化里受欺压、反抗、黑化，成长率更高。这段经历由 AI 按快照和恶魔小队的环境生成，并有引擎给出的数值成长。
  - 之后他作为宿敌出现，**带着你当初的选择**：你造了谁，他就也造了谁，而那个人在恶魔小队里多半有悲惨的下场。
  - 原剧情模式按原著：复制体郑吒、复制体楚轩、复制体铭烟薇、复制体罗甘道、赵缀空的复制体等。
- **天神邀请**：成为队长时触发。拒绝，留下带队；接受，角色离队加入天神小队，原队换新的引导者从头再来，新队长只有信息查询权（原著规则）。扮演个人模式下，这是一条可以真正走下去的分支。
- **特殊小队的出场**：主神按议程把它们放进别队的片里，作为对照实验或加压手段（生化危机二、魔戒、最终一战）。
- **天使联盟**：后期天神小队拉拢弱队结盟，对抗恶魔小队，成为团战里的政治力量。
- **养殖队**不是主神设计的，是部分队伍自己选择的策略（少数强者压榨新人）。主神对它们的团队评价不高，楚轩认为养殖队开锁程度普遍不高（L11763）。

## 十一、失败的代价（以及成功的代价）

### 11.1 生化危机二团灭后的代价链
团灭不是"评价清零"这一件事，而是一连串互相咬合的代价，几乎决定了下半部前半段的全部剧情：

| 代价 | 原著 | 出处 |
|---|---|---|
| **队友全部死亡** | 除郑吒外所有人都死了；郑吒自己也死了，是靠詹岚给的重生十字章当场复活 | s06、L7328~7330 |

### 11.2 代价的分层
| 失败的层级 | 代价 |
|---|---|
| 一次扣分（泄密、杀剧情人物、保护对象死亡、支线失败） | 点数、支线；结算后为负就被抹杀 |
| 任务失败 | 按任务规定扣点或抹杀（全丢要塞、超时未杀蝎子王……） |
| 个人死亡 | 永久死亡，除非付出复活代价：祭坛 B + 7000/8000，或主神空间内按生前所得 ×2；每人只有一次；死亡那部片的所得不计；造物随制造者消失 |
| 队长真正死亡（不是当场复活） | 队长职务被解除，失去预知下一部片、快速查询等权限，评价减分；要等新的引导者再考验一次（天煞）（L20006、L21846） |
| 团战落败 | 己方每死一人 −1 分；负分由幸存者承担，可能被抹杀；对手拿走击杀奖励而变强 |
| 团灭（有人靠道具活下来） | 以上全部，加上评价清零、记录消失；幸存者独自承担负分和整个复活计划 |
| 全灭（没有一个人活下来） | 这一代中洲队终结；房间、造物一并消失；只有纪念石壁留下；主神空间迎来新一代新人和新的引导者 |

### 11.3 成功也有代价
楚轩分析过另一条路："如果中洲队继续胜利，那么「主神」很可能会全力培养，也即不停加大难度来让中洲队进化"（L8005）。
- **成功的代价**：评价越来越高，主神会持续加码，片更少更凶，更早遇上特殊小队，没有喘息的成长窗口。
- **失败的"补偿"**：评价清零，回到普通课程，有了成长窗口（下半部前半段的支线都很丰厚）。

所以主神的逻辑是**两头都不让你舒服**：赢了就往死里加压，输了就要用很多部片去偿还。

### 11.4 对游戏设计的意义
- **失败不是"读档重来"，而是新的一段剧情。** 只要还有一个人活着，团灭就进入**重建篇**：
  1. 幸存者扛下负分；
  2. 评价清零，难度回到普通课程；
  3. 去找复活手段（复活真经、祭坛、主神空间内的双倍复活）；
  4. 一个个凑钱复活，决定先救谁，在复活和变强之间取舍；
  5. 这期间可能要独自或带着剧情人物盟友去闯片。
- **复活用掉的是一次性的机会**，所以后期的每一次死亡都更重。代价要跨越很多部片持续生效，而不是当场结清。
- **全灭也不是游戏结束**：这一代人的故事结束，纪念石壁留下名字；玩家可以作为新一代中洲队继续（新的新人、新的引导者），之前的石壁还在广场上。原剧情模式里这算一个"坏结局"分支；沙盒模式里这就是正常的世代更替。
- **原剧情的分支**：生化危机二在原著里是团灭。如果玩家没有团灭，下半部就会走另一条同样符合主神逻辑的路：评价不清零，主神全力培养，难度持续加码，没有成长窗口。原著的下半部是"失败之后"的那条线；另一条线需要按议程逻辑重新推演。
- **存档**：铁人模式（一个存档，失败就是失败）是原剧情和沙盒的推荐玩法；另提供一个宽松选项给想体验剧情的人。
