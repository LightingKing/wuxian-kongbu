# 《生化危机一》与主神空间重做：设计

> 状态：2026-11-10 与用户逐节讨论，六节全部确认。这是一个里程碑的设计；计划 22～25 各自另写实施计划。

## 背景

用户对现在的完成度不满意：和 2009 年那款 RPG Maker XP 同人游戏比，我们只有一部片的 8 个单屏房间、代码画的占位图、菜单式的主神空间。差距在美术和内容量，不在引擎（Godot 4.7 不换）。那款游戏我们不移植、不续做，只借鉴 RPG 的通用做法；章节内容按原著自己写。

## 已定的选择

| 问题 | 选择 |
|---|---|
| 第一个里程碑 | 先把《生化危机一》和主神空间重做到位，再做新章节 |
| 美术来源 | 只用免费素材：许可允许我们用的免费图块包；包里没有的由 Codex 画（人物行走图、战斗小人、独有的场景件）。不买素材 |
| 地图形式 | 每个地点一张多屏大地图，镜头跟随，门连接地点、过门照样走时间 |
| 主神空间 | 广场 + 各人房间 + 训练室，人物按时段在不同地方 |
| 遇敌 | 敌人在地图上游荡，碰到就开战，可以绕开（要改规则） |
| 地图制作 | 用 Tiled 做地图（文本格式），游戏载入时转成 Godot 的图块层 |

## 用到的 skills（awesome-gamedev-agent-skills）

router 从 `project.godot` 判定是 Godot 项目，这次任务选了下面几个；它们对设计的具体影响写在对应小节里，标注【skill 名】。

| skill | 用在哪 |
|---|---|
| `godot-tilemap` | 第 2 节：用 `TileMapLayer`（旧的 `TileMap` 节点已弃用）、图块自定义数据当碰撞、带镜头时鼠标坐标的换算、高家具的遮挡 |
| `camera-systems` | 第 2 节：用 `Camera2D` 自带的平滑、边界和拖拽边距（死区），在角色移动之后再跟 |
| `level-design` | 第 2、4 节：先灰盒、试玩、再上图；按节奏曲线排紧张和喘息；检查关键路径不会卡死 |
| `create-game-assets` | 第 3 节：先定美术方向和清单，先批准一个样板房间再成批做，图块要过 3×3 接缝测试，每个文件记来源和许可 |
| `rpg` | 第 5 节和以后：补任务日志、让变强看得见；内容按数据定义 |
| `godot-gdscript-headless-testing` | 第 6 节：测试运行器改成等一帧再跑，测试才能把场景放进场景树；靠退出码和脚本错误判定失败 |
| `game-ai` | 第 4 节：敌人用有限状态机（巡逻、察觉、追击、搜寻、回位），转换写在各状态里；目标换格子才重新寻路；卡住超时就换状态 |
| `game-ui-ux` | 第 5 节：面板按"界面栈"压上去、Esc 弹出；每个面板打开时有默认焦点，键盘能操作；左上角信息随事件更新，不每帧去读 |

## 1. 结构与顺序

四个计划，每个做完都能玩：

1. **计划 22：地图系统 + 样板房间。** Tiled 地图载入、镜头、碰撞、地图上的物件；用免费图块重做蜂巢入口大厅，在游戏里判断；美术就在这一步定下来。重写任务卡 007（按图块包的人物尺寸出行走图，取消"每个房间一张整图"）。
2. **计划 23：8 个地点全部改成多屏地图**，加支路小房间；剧情人物、搜索点、灯都成为地图物件；旧的字符地图退役。
3. **计划 24：游荡的敌人。** 巡逻、视线、追击、潜行；碰到就开战，打倒的敌人不再出现；用自动跑局重新平衡第一部片。
4. **计划 25：可行走的主神空间 + 日常作息。** 广场（光球）、各人房间、训练室、出发日的光柱；人物按时段走动，晨会在广场演出来，现有菜单改成从地点和人物打开。

Codex 从计划 22 的样板房间批准后并行出图（只用 codex 登录渠道）：7 个轮回者 + 8 个剧情人物 + 萝丽的行走图；丧尸、丧尸犬、爬行者在地图上的样子；免费包里没有的场景件（列车车厢、火焰女皇投影台、主神空间的地面和墙、光球、传送光柱）；战斗小人（任务卡 006）。

**完成标准：** 从车厢穿过蜂巢、回到主神空间、过九天、出发，全程可以走，画面上没有占位图。

## 2. 地图系统

**文件**
- 每个地点一个 Tiled 文本地图：`game/data/maps/biohazard1/<地点>.tmj`；固定用 Tiled 1.11 的格式。
- 图块集用描述文件 `.tsj`（文本，列出每块图块的属性，如"挡路"）。
- 图片放本机 `game/art/tiles/`，不进仓库（多数免费许可也不允许转发原图）；每个包的来源和许可记在 `art_src/tiles/LICENSES.md`。

**地图里有什么**
- 图块层，每层一个 `TileMapLayer`【godot-tilemap】：地面、墙、装饰、上层（画在人物上面的门楣、管道、高柜顶）。
- 物件层：门（通往哪个地点）、各入口的到达点和开场位置、剧本的搜索点、剧情人物站位、敌人出生点和巡逻路线（折线）、灯和光晕、踩进去触发剧本事件或插图的区域、主神空间里每人每个时段待的位置。
- 挡路靠图块自定义数据 `blocks`【godot-tilemap】：画了墙块就自动挡路。高家具占两格时，上面那格放上层，人从后面走过会被挡住（不用逐格排序）。

**在游戏里**
- 新的读图代码回答和现在一样的问题（能不能走、门通哪、从哪进来、寻路），地点场景基本不用改。
- 缺图时（自动测试里、正式图到之前）画灰色占位块，不报错——这也就是灰盒：先用灰块把地图试玩顺了再上图【level-design】。
- 镜头用 `Camera2D`：自带平滑、地图边界、一点拖拽边距（小幅走动镜头不晃），在角色走完一步之后跟【camera-systems】。一屏 30×16 格，地图多大都行。
- 一步一格不变；点地图时先把鼠标位置换算到图块层的坐标（考虑镜头滚动）再取格子【godot-tilemap】。
- 现有灯光系统改从地图物件读灯。

**检查**
- 自动测试检查每张地图：剧本里每个地点都有图；门只通向相邻地点、相邻地点都有门；每个到达点和搜索点走得到；剧情人物和巡逻路线都在能走的格子上；触发区指向的剧本事件存在。
- 关键路径检查：按剧本的通路开关（例如激光通道要关掉激光才能过），从开场走到每个必经地点不会卡死【level-design】。
- 截图工具给每张地图截图。

**做图**
- 我用生成脚本写地图文件（布局 + 装饰）；你随时可以用免费的 Tiled 打开看或者重画。

## 3. 美术

**先把技术规格定死**【create-game-assets】
- 图块 16×16；像素层 480×256、整数放大 4 倍、最近邻采样（现有设置不变）；3/4 俯视（看得到家具顶面和正面，墙有一格高的墙面）。
- 地图上的人物：单帧 16×32（一格宽、两格高，Q 版 2.5～3 头身，可见高度约 28 像素），行走图 4 列 × 4 行（行：下、左、右、上；列：站立、迈步、站立、迈步），脚底中点对齐格子。这是多数免费 16 像素图块包的人物比例，混在一起不突兀；任务卡 007 原来写的 32×32 改成这个。
- 免费包自带的人物图（如果用来当路人、研究员丧尸）排法各不相同，用 sprite-gen 的图集工具重排成上面的格式（按 AGENTS.md，不另写同类脚本）。
- 战斗画面不变（单帧 48×48、人物约 32 像素高，任务卡 006）。

**美术方向写成可检查的条目，不写"好看""有氛围"**【create-game-assets】
- 底图是"照明均匀、偏中性"的白天色，恐怖感交给游戏的光照（环境光、灯、手电筒），这样同一套图块能用在亮的大厅和全黑的楼梯井。
- 统一调色板：先在样板房间里比较"图块包原色"和"映射到共用 32 色调色板"两种，选更协调的；选了映射，所有图块和 Codex 的图都用同一个已有的确定性映射工具（任务卡 003 的 `game/tools/pixelize_scene.py` 的调色板映射，不缩放）。
- 边缘处理一致：只选描边方式相近的包（都描深色外框，或都不描），不混用。
- 每类东西一眼要分得清：能搜索的柜子比普通家具亮一档；门有门框和地面过渡；地面上的装饰影子不能看起来像墙。

**素材来源和记录**【create-game-assets：provenance】
- 只用免费素材。"免费"不等于许可：每个包都到作者原页面核对条款（能不能用于非商业项目、要不要署名、能不能改），优先 CC0；条款写不清的不用。
- 每个文件记在清单 `art_src/manifest/field.json` 里（沿用 skill 的清单格式：编号、用途、路径、尺寸、锚点、来源网址、作者、许可、署名、改动、是否已在游戏里看过、谁批准的）。清单和 `art_src/tiles/LICENSES.md` 进仓库，图片不进。
- 标题画面加"致谢"，列出需要署名的素材作者。

**先批准一个样板房间，再成批做**【create-game-assets】
- 计划 22 里用 2～3 组候选免费包各拼一版蜂巢入口大厅，在游戏里带光照截图，再放一个占位的郑吒；你选一版，它就是之后所有图的"合同"：比例、颜色、光照、细节密度都以它为准。
- 图块过关前做 3×3 重复的接缝测试（满尺寸和缩小各看一次），用 skill 自带的接缝/对比图脚本出对比图。

**免费包没有的，Codex 画**（只用 codex 登录渠道）
- 人物行走图：先画郑吒一套，放进样板房间批准后，其余 15 个人（6 个轮回者、8 个剧情人物、萝丽）以它为参考成批出，保证比例、调色板、描边一致。
- 敌人在地图上的样子（丧尸、丧尸犬、舔食者），给第 4 节的游荡敌人用。
- 免费包里大概率没有的场景件：高速列车车厢（座椅、车窗、车门）、火焰女皇的全息投影台、主神光球和传送光柱。按样板房间的规格画成图块或物件，过同样的接缝和对比检查。
- 任务卡 006（战斗小人）照旧；任务卡 007 按本节重写。
- 计划 21 加的"每个地点一张整图"的接口在计划 22 移除。

## 4. 游荡的敌人

**规则和表现分开**（沿用"规则全在 core、界面只表现"）
- **规则（core）**：剧本里每个地点可以有几组"游荡敌人"，写清楚每组是什么敌人、几只、什么时候出现（到第几分钟、或者某个剧情开关之后，例如火焰女皇被关掉、蜂巢里的丧尸放出来以后）。core 记住哪组已经打倒（存档里也记），提供"和第几组交战"的入口，交战就像现在的搜索遭遇一样排一场战斗。
- **先手**：从敌人没发现你的时候碰上去 = 偷袭，我方先动；被它追上 = 被偷袭，敌方先动；正面撞上 = 照常。用现有战斗的先手倍率（initiative）实现，不另做战斗系统。起始数值：偷袭时我方 2.0、敌方 0.5，被偷袭时反过来，正面都是 1.0；计划 24 用平衡跑局再调。
- **打倒的不再出现**；剧本里写好的战斗（主机房的八只丧尸、爬行者等）照旧，游荡的敌人是额外的、较轻的组（1～3 只丧尸、1～2 只丧尸犬，后期有爬行者）。搜索柜子时惊动敌人的遭遇也保留。
- **地点内走动不走时间**（和现在一样）；战斗照现在的规则花时间。

**敌人怎么动（界面层，`game-ai`）**
- 每组在地图上一个领头的小人，碰到它就是和整组交战；队友不会触发。
- 状态机【game-ai】：
  - **巡逻**：沿地图上画的路线走（丧尸慢、丧尸犬快、爬行者更快）；
  - **察觉**：看见你先停一下、头上冒"！"，给玩家半秒反应；
  - **追击**：按格子寻路追你，你换了格子才重新算路；
  - **搜寻**：看丢了就去最后看见你的地方转一圈；
  - **回位**：回到巡逻路线。
  - 卡住超过几秒就强制换状态，不会顶着墙不动【game-ai】。
- **视线**：按格子算视线，墙和家具挡视线；巡逻时只看前方一个扇形，丧尸犬近距离能"听到"身后的你。黑暗地点敌人看得更近（视距打折），但你也只能看到手电筒照的地方。
- **速度**：玩家一步 0.13 秒；丧尸比你慢，可以甩掉；丧尸犬和你差不多快，只能绕开或硬打；爬行者比你快。
- 对话、窗口、插图、菜单打开时敌人全部停住；回到地点时敌人回到出生位置。

**节奏和平衡**【level-design】
- 按地点排紧张度：车厢（开场、教学，无敌人）→ 大厅 → 楼梯井（黑暗）→ 激光通道（剧情）→ 主机房（高潮）→ 实验区走廊（战斗）→ 冷冻仓库、下水道（黑暗、丧尸犬、爬行者）。具体每组放哪在计划 24 里按这条曲线定，放喘息点，不连续堆战斗。
- 每张图都要留一条能绕开所有游荡敌人的路线（巡逻路线不能把唯一的通道整个封住），地图检查会验证。
- 自动跑局加两种打法："见一组打一组"和"全部绕开"；目标：两种都能通关，见一组打一组的团灭率不明显高于现在，绕开的打法拿不到游荡敌人的击杀点数。击杀点数照现有规则算，不破坏剧本里锁定的点数锚点。

## 5. 可行走的主神空间

**一天分三个时段**（规则在 core 的主神空间逻辑里加，现在只有"第几天"）
- **早晨**：所有人聚到广场开晨会（现有的晨会事件，在广场上演出来：台词进对话框，选择弹窗口）。
- **白天**：每个人去自己的地方（训练室、广场、自己房间……），你可以走过去找人说话、做事。
- **夜晚**：大家回房间；在自己房间睡觉 = 过一天，到第二天早晨。
- 时段怎么往前走：晨会结束进入白天（那天没有晨会事件，就在广场打个照面直接进入白天）；训练、陪伴萝丽这类"花一整天"的事做完到夜晚；在房间里睡觉到下一天早晨。兑换、加属性、说话这些不花时间。天数规则（休息天数、出发条件）照旧。

**作息数据**（`data/hub/routines.json`）
- 每个人每个时段待在哪里，可以带条件：受了伤的待在房间、和郑吒关系差的不在广场露面、萝丽跟着郑吒或者待在他房间、阵亡的人房间锁着。
- 地图上标好地点（每个人的房间、训练室、广场上的几个位置），作息只说"去哪个地点"，具体站哪格由地图决定。

**地图**
- 一张 Tiled 地图：中央是广场和主神光球，四周是每个人的房间门，一侧是训练室；出发那天广场中央出现传送光柱。在主神空间里过门不花时间。
- 主神空间不在免费图块包里：地面、墙、光球、光柱按第 3 节由 Codex 画（白色、带淡淡格线的空间）。

**现有菜单改成从地点和人物打开**【game-ui-ux】
- 光球：兑换、加属性、修复、造人、问主神。
- 训练室：训练技能、和训练傀儡对练。
- 队友：走过去按 Enter 说话（现有的 AI 对话），说话面板里能看关系和服从度。
- 自己房间：睡觉（过一天）、和萝丽相处；存档仍用现有的存档槽和自动存档。
- 传送光柱：出发（只在能出发的那天出现）。
- 面板按"界面栈"一层层压上去，Esc 或右键退一层；每个面板打开时有默认焦点，键盘能完整操作；鼠标照常可用。
- 左上角显示"第几天 · 时段 · 郑吒的点数"，只在对应事件发生时更新。

**任务日志**【rpg】
- 新增一个任务日志面板（地点场景和主神空间都能按键打开）：当前恐怖片的主线任务和剩余时间、支线、晨会定下的事；完成的划掉。这是 `rpg` skill 指出我们缺的两样之一；另一样"变强看得见"在第 6 节的验收里检查（加属性、学技能、觉醒天赋都有明显提示）。

## 6. 测试与验收

**先改测试运行器**【godot-gdscript-headless-testing】
- 现在的无界面测试在场景树还没建好时就跑（计划 21 里因此没法测打字效果）。改成先等一帧再跑，测试就能把场景放进场景树，测镜头跟随、打字、面板栈、敌人按时间走动。失败判定照旧：统计失败数决定退出码，再查输出里有没有 `SCRIPT ERROR`（运行时错误会让一个测试半途中止，不能当成通过）。
