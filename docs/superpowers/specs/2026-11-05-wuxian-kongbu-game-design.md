## 0. 目标与边界

**目标**：做一款以《无限恐怖》为蓝本的 2D 回合制游戏。核心体验是原著的"在主神空间变强 → 进恐怖片活下去 → 结算"循环，机制和细节尽量贴合原著。

**已经和你确认的决策**

| 项 | 决定 |
|---|---|
| 核心玩法 | 暗黑地牢式：据点（主神空间）+ 远征（恐怖片）+ 回合制战斗；永久死亡、恐惧值、新人招募 |
| 平台 | PC（Windows，键鼠）+ 安卓手机（横屏，触屏），从第一天起两套交互都做 |
| 模式 | 两条轴可以组合：**内容**分原剧情 / 沙盒，**操控**分扮演整队 / 扮演队伍中一人 |
| 推进方式 | **慢慢做，一个恐怖片一个恐怖片打磨**，按原著顺序。第一个里程碑 M1 是《生化危机一》+ 第一次休整；M2 是《异形一》+ 第二次休整，楚轩登场，完整检验智谋线与内斗。上半部是铺垫，每部片引入一个核心系统 |
| 关卡结构 | 地点图 + 剧情时钟 |
| 战斗阵型 | 不限人数的战场：前、中、后三排，速度驱动行动时间轴（CTB） |
| 美术 | 玩法画面（战斗、地点、主神空间）用 Q 版像素；剧情（立绘、插图、过场）用日系动漫插画；都由 Codex 生图（第 11 节） |
| 协作 | 你在 Claude 与 Codex 之间协调，Codex 任务以任务卡文件交付 |
| 出题 | 不照抄原著任务，而是复现主神的**出题机制**：难度相对于队伍评价、克制最强项、绑定剧情、平衡"势"、指向成长瓶颈（见 [`docs/core-mechanics-analysis.md`](../../core-mechanics-analysis.md) 第一节） |
| 奖励 | 击杀奖励和支线等级跟**相对难度**挂钩，碾压式的击杀不给分（第二节） |
| 人物 | 主神不选没用的人：每个轮回者都有背景、隐藏天赋、心魔、潜力，区别只在发挥不发挥得出来（第三节） |
| 兑换 | 不局限于原著，广泛取材，目标 2000 条以上；用效果积木 + 定价公式保证大量也平衡（第四节） |
| AI | **主神和 NPC 由 AI 接管**：AI 提议，规则引擎裁决（第五节） |
| 养成 | 十条成长线；兑换是"主神看得见的成长"，锻炼、修炼、实战、自创技能、基因锁、羁绊是"看不见的成长"（第六节） |
| 陪伴 | 人造人是完整的 AI 角色，有心情、愿望、记忆，是制造者的锚也是软肋（第七节） |
| 内斗 | 关系网、凝聚力、派系、团队文化、冲突升级阶梯、可编辑的团队章程；AI 队伍各有文化，可被挑拨（第八节） |
| 智谋 | **智者不可替代**：智力是一种能力而不是属性加成——推理揭示隐藏信息、发现规则漏洞、估算成功率、布局（计策积木 + 引擎规划器）、智者对弈、战场意图预判、科技研发、情报与"势"。智者的价值 = 信息 + 选项 + 概率，且不计入主神评价（第九节） |
| 主神 | **有目的的行动者，不是死物**：议程层（标准培养课程、异常察觉与纠正、潜力追踪、群体实验）决定"这一步想推动什么"，出题层决定手段；会设计"按正常途径必死、只留一个出口"的强制关卡（死神来了2）；每个决定附隐藏理由，智者可以推理（第 1.0 节） |
| 特殊小队 | 恶魔小队（复制潜力突升者，放进"恶魔心肠"环境）和天神小队（集中各队队长）是主神的**进化对照实验**；恶魔小队是玩家角色的镜像生成器，天神邀请是一道考题（第十节） |

**不做（第一阶段）**：商业发行、联网、多人、配音。
**版权**：原著和其中借用的电影 IP 都有版权。本项目定位为**个人同人作品，不公开发行**；如果以后想公开，需要改名并原创化人物与敌人。

## 1. 里程碑与路线图

**节奏（已确认）：慢慢做，一个恐怖片一个恐怖片打磨。** 按原著顺序推进，每部片（连同它前后的主神空间休整）是一个里程碑，打磨到位再做下一部。系统在第一次被某部片需要时才实现，但架构从第一天起就为全部系统留好位置。

上半部（生化危机一 → 生化危机二）是铺垫，真正的精彩在下半部。所以上半部的每部片**各引入一个核心系统**，像循序渐进的教学；到生化危机二结束时，所有系统都已就位。

| **F1** AI 接入层 | 可切换服务商（Anthropic / OpenAI 兼容）、意图格式与校验、世界设定库、人设与记忆、离线兜底 |

## 2. 核心循环

```
主神空间（休整 N 天）
  ├─ 结算：奖励点数 + 支线剧情（分级、可拆合）
  ├─ 兑换：属性 / 血统 / 技能 / 装备 / 道具（原著价格）
  ├─ 修复、复活、造人、训练、队伍管理
  └─ 进入光柱（30 秒）
        ↓
恐怖片（远征）
  ├─ 手表：任务、倒计时、限制条件（百米绑定、禁言……）
  ├─ 地点图：移动、搜索、休息、对话，每个行动都耗剧情时钟的时间
  ├─ 剧情时钟：原片事件按时发生（剧情惯性）；玩家可以提前干预，改变剧情、触发支线
  ├─ 回合制战斗（不限人数，三排站位，CTB）
  ├─ 恐惧值 → 基因锁觉醒 / 精神崩溃
  └─ 达成条件或倒计时结束 → 回归
        ↓
结算 → 回到主神空间
```

## 3. 角色与属性

### 3.1 六项基础属性（原著）
智力、精神力、细胞活力、神经反应速度、肌肉组织强度、免疫力强度。常人各约 100。**10 奖励点数 = 1 点属性**（原著）。

### 3.2 派生战斗属性（游戏公式，可调）
| 战斗属性 | 公式（初版） | 原著依据 |
|---|---|---|
| 生命上限 | 40 + 0.6×细胞活力 + 0.4×肌肉 | 细胞活力 = 复原，肌肉 = 体格 |
| 速度（CTB） | 神经反应速度 | 神经反应 = 看清高速物体 |
| 物理攻击 | 武器基础 × (肌肉 / 100) | 肌肉 = 力量、速度 |
| 命中 / 闪避 | 由神经反应决定 | — |
| 推理、规划、研发、指挥 | **智力**，再加领域熟悉度、天赋和已掌握的信息（见 3.8） | 楚轩、萧宏律 |
| 精神抗性、恐惧抗性 | 精神力 | 精神控制、心魔 |
| 感染 / 毒素抗性 | 免疫力 | 免疫 = 抗病毒 |
| 战后自然恢复 | 细胞活力 | 复原速度 |

### 3.3 能量池
**内力**（气功）、**血族能量**（血族血统），以后陆续加入精神力值、魔网次数、真元力、魔力、妖力、能量石等。每种能量都有上限、恢复规则和消耗它的技能。M1 只做内力和血族能量。

### 3.4 基因锁（核心成长线）
- 阶数 0~5，记在角色身上，**不能兑换，只能在战斗中觉醒**（原著：主神强化最多帮到第三阶）。
- **发挥率**：原著说"普通人兑换 A 级属性只能发挥约 10%，第四阶才发挥 100%"。直接照搬会让前期兑换没有手感，所以发挥率**只作用于 B 级及以上兑换项的效果强度**：0 阶 50%、一阶 70%、二阶 85%、三阶 95%、四阶 100%（可调）。
- **觉醒触发**：生命低于 25% 或恐惧值满时做一次觉醒检定。概率取决于精神力、隐藏的"潜力"值、当前恐惧值。成功则基因锁升一阶，并进入"基因锁状态"若干回合（大幅加速、加攻、屏蔽痛觉）；战后出现**后遗症**（脱力、吐血、生命上限暂降，持续若干个地点行动）。
- 第一阶觉醒前不能主动开启；二阶起可以作为主动技能开启，持续越久后遗症越重。
- 第三阶"模拟"：开启后可以借用一名队友某个技能的 30~60% 效果，持续越久头痛越重（生命损失）。
- 第四阶要过**心魔关**（下半部猛鬼街起的心魔剧情战），M1 不做。

### 3.5 恐惧值（0~100）
- 增加：看到可怕的东西（剧情事件、怪物登场）、队友死亡、受重伤、处于黑暗中、遭遇剧情改变。
- 减少：休息、伙伴的鼓舞类技能、心神凝聚之类的强化、胜利。
- 恐惧满时检定：**觉醒**（见 3.4，资深者和高潜力者概率高）或**崩溃**（逃跑、发呆、误伤、拒绝命令；新人概率高）。
- 新人崩溃时可能逃离绑定的剧情人物，被主神抹杀，对应原著小胖子、牟钢的死法。

### 3.6 人物构成：背景、天赋、心魔、潜力、性格
（依据 `core-mechanics-analysis.md` 第三节）
- **现实背景**：职业、经历、技能，决定初始能力和对话。
- **天赋**（隐藏）：和背景相关、超出常人的潜质，带**发挥条件**（遇到某种危机、兑换到契合的强化、被队友点破、跨过心魔）。条件不满足就是"发挥不出来"；玩家可以通过观察、对话、主神问答的蛛丝马迹去发现。
- **心魔 / 心灵漏洞**：决定恐惧崩溃时的表现，也是第四阶心魔关的内容；克服后天赋大幅增强。
- **潜力**：觉醒概率和成长上限。
- **性格**：AI 接管该角色时的行为依据。
- **天赋契合**：契合的兑换项更便宜、发挥率更高，或可绕过素质门槛。
- **原著人物**按原著设定填写（例：詹岚 = 精神力天赋，可绕过 3000 精神力门槛；齐腾一 = 古文字，可免费学亡灵圣经魔咒）。原著里早早死去的新人（李萧毅、牟钢、小胖子、中年妇女）也有自己的天赋，原著里只是没来得及发挥——在游戏里，他们能不能活下来、发挥出来，取决于玩家。
- **新人生成**：主神按队伍画像补缺；每批至少一个和当前或下一部片相关的**钥匙型天赋**。

### 3.7 养成：十条成长线
（依据 `core-mechanics-analysis.md` 第六节）

| 成长线 | 来源 | 计入主神评价？ | M1 |
|---|---|---|---|
| 兑换强化 | 点数 + 支线 | 计入 | ✓ |
| 锻炼 | 休整天数；"练到受伤再修复"收益更大 | 不计入 | ✓ |
| 能量修炼 | 自然增长、提纯、凝炼（长周期进度条） | 不计入 | 内力自然增长 |
| 熟练度 | 训练、实战使用 | 不计入 | ✓ |
| 战斗意识 | 真实的高危战斗 | 不计入 | ✓ |
| 领悟与自创技能 | 攒领悟值 → 顿悟；AI 用角色已有的效果积木拼出新技能，引擎校验预算并强制带代价；可继续进化 | 不计入 | 只攒领悟值 |
| 基因锁与心魔 | 濒死觉醒、心魔关；第四阶中级生成个人化的心灵之光 | 不计入 | 一阶觉醒 |
| 天赋觉醒 | 满足发挥条件 | 不计入 | ✓ |
| 器物 | 进化、认主、改造、研究 | 兑换部分计入 | — |
| 羁绊 | 共同作战、救命 → 解锁合击技 | 不计入 | 关系数值 |

**核心取舍**：兑换快，但主神看得见，会抬高难度、压低奖励；其他成长慢、要冒险，但真实战力会超过主神的估计。

### 3.8 智谋线：智力是能力，不是加成
（依据 `core-mechanics-analysis.md` 第九节。原著里中洲队一次次以弱胜强，主要靠楚轩、萧宏律，而他们几乎不兑换强化。）

**原则**：智者的价值 = **信息 + 选项 + 概率**。玩家仍然拍板，但"能知道什么、能想到什么、能算出几成胜率"取决于队里有谁。

| 能力 | 做法 |
|---|---|
| 推理 | 每部片藏着隐藏事实（敌人弱点、支线条件、文字陷阱、剧情走向、对手计划、卧底）。玩家拿到线索；智者花时间推理，得出**带可信度的推论**，准确度看智力、线索、领域熟悉度、天赋；推论可能出错，两个智者可以互相校验 |
| 规则发现 | 引擎里有一层隐藏规则和漏洞（造人当保镖、零件绕开支线、"记录"回旧片、冷藏尸体省钱、新人免费复活、自创技能不计评价……），**被智者发现之前在机制上是锁住的**；发现后带来新路线、新兑换页 |
| 概率 | 计划和决策的成功率只有队里有智者时才显示，精度随智力提高（"三成，已经很好了"） |
| 布局 | 地图之上的计划层，由**计策积木**组成（诱饵、伏击、分兵、佯攻、示弱、欺骗、借刀、制造混乱、斩首、撤退路线、陷阱、造势）。智者提出计划：**引擎规划器真正去搜索**，智力决定深度和质量；AI 只用人物口吻讲出来，并决定瞒不瞒（楚轩的"我骗你的"）。计划会改写战斗的初始条件，可以绕开战斗、改写剧情 |
| 对弈 | 敌方智者用同一个规划器布局；每个计划都带着对敌人的假设，假设被打破计划就出问题；欺骗类积木往对方脑子里塞错误假设。团战首先是智者之间的较量 |
| 战场指挥 | 有智者在小队里或通过心灵锁链相连时，CTB 时间轴显示**敌人下一步的意图**（准确率随智力提高）；可以下条件预案、协调合击；战前布置陷阱、选地形 |
| 科技研发 | 智者 + 材料 + 时间 + 知识来源 → 破译、发明、改造。自造科技能绕开支线门槛，且大部分不计入主神评价 |
| 情报与"势" | 在电影世界里建立情报网，操纵舆论，取得地位，与剧情势力谈判 |

- **道德张力**：规划器的最优解常常带牺牲；执行它会扣队员的信任，"理性之道"和"情义之道"的冲突落到数字上，接入内斗系统（7.4）。
- **模式差异**：扮演整队时，智者是你的参谋部；扮演郑吒时，楚轩由 AI 接管，可能瞒着你布局；扮演楚轩时，推理、布局、研发工具全开，但战斗力很弱。
- **主神看不见智谋**：智者是全队最大的隐藏战力乘数。

## 4. 战斗系统

### 4.1 战场
- 敌我各有前、中、后三排，每排容量由战斗数据决定：默认 4（每方 12 个），大场面可以到 6（每方 18 个）。大型单位占多个格。
- 近战技能默认只能打敌方前排，除非技能写明"可达"；远程、投掷、法术按技能定义选排。
- **换位**是一个行动；有些技能会推拉站位。
- 手机上战场可以缩放，并自动对准当前行动单位；PC 上悬停查看详情。

### 4.2 行动顺序（CTB）
- 每个单位的下次行动时间 = 基础延迟 / 速度；技能可以带额外延迟或"加速"。
- 界面上方显示未来 10 次行动的时间轴，玩家能预判敌人先手。

### 4.3 行动类型
攻击/技能、使用道具、换位、防御、开启基因锁（二阶起）、撤退（个别战斗不允许）。剧情战斗可以有**特殊行动**，比如激光通道里的"卧倒""贴门"，需要在正确时机选。

### 4.4 技能定义（数据驱动）
每个技能是一条数据：可用站位、目标站位、目标类型（单体/一排/全体/随机 N 个）、消耗（内力/血族能量/生命/恐惧）、冷却、伤害公式、附加状态、特殊标签（对灵体、破甲、无视护盾……）。

### 4.5 状态效果
感染倒计时（被咬后 N 回合内不用解毒剂就变丧尸）、酸蚀（护甲下降、持续伤害）、流血、脱力、恐慌、失明、灵体（物理伤害无效）、护盾、基因锁状态等，全部由数据定义。

### 4.6 敌人 AI
每种敌人一份行为数据：攻击偏好（最近、最弱、最有威胁）、特殊规则（爬行者靠热感和嗅觉，黑暗中命中不降；丧尸偏好咬已经受伤的人），以及阶段转换。敌人**提前确定下一步意图**，玩家能看到多少、看得准不准，取决于队里的智者和侦察能力（3.8）。

### 4.7 剧情人物与新人
剧情人物（马修、艾丽丝……）和不归玩家指挥的新人由 AI 控制。他们的死活影响任务和支线。

### 4.8 死亡
生命归零即死亡（资深者在原著里也会真死），没有"濒死缓冲"。重生十字章之类的道具除外。死亡是永久的，只能通过复活规则挽回（见 7.5）。

## 5. 恐怖片（远征）系统

### 5.1 地点图
每部片是一张由地点和通路组成的图。每个地点有：描述、背景图、可搜索物资、可能的遭遇、危险度、光照（黑暗会加恐惧）。移动耗时间；有些通路要条件才能走（门禁卡、激光、被堵）。

### 5.2 剧情时钟
- 全局时间以分钟计。每个行动（移动、搜索、休息、对话、战斗）都耗时间。
- **剧情事件表**：每条事件有触发时间或触发条件、地点、效果（对话、战斗、状态改变、NPC 移动、开门关门）、**惯性等级**。
- **剧情惯性**：原片事件默认按时发生；玩家提前干预（救下本该死的人、提前关门、威胁电脑）可以让事件改写或取消，代价是可能触发难度提升或连锁事件。
- 改变剧情产生**支线完成**（对应原著"逆转剧情、救下必死配角"），由事件数据声明支线等级和奖励。

### 5.3 手表
显示主线任务、倒计时、击杀计数、限制条件。限制条件由数据定义，M1 里用到：
- **百米绑定**：不得离开剧情人物马修 100 米。图上表现为"必须在马修所在地点或相邻地点"；超出会警告，持续超出则被抹杀。马修死亡后限制转移，救下马修后限制解除。
- **禁言**：剧情人物在场时，选择泄露主神信息的对话选项扣 10 点。

### 5.4 分队
全队可以在地点图上拆成多个小队，各自行动，时间统一推进。战斗只牵涉所在地点的小队。M1 里出现"留守主机房还是跟雇佣兵走"的分兵选择。

### 5.5 任务从哪里来
**主神是有目的的行动者，分两层决策**（详见 `core-mechanics-analysis.md` 1.0~1.4）：
- **议程层：这一步想推动什么。** 主神给每支队伍、每个重要个体维护隐藏议程：
  - 标准课程走到哪一步（引导者 → 队长 → 成长窗口 → 团战 → 加难 → 瓶颈试炼 → 终局）；
  - 有没有异常（例：张杰这种"半引导者"、引导者拖延考验、违规攻击别队成员），以及待执行的最后通牒；
  - 每个人的潜力和潜力突升（造人、凭自身属性开锁……）；谁被复制进恶魔小队；谁在"拖后腿"；谁卡在什么瓶颈。
  
  据此决定这一部的目的：让队伍成长、加压纠正异常、强制考验、对照实验、瓶颈试炼、终局。
- **出题层：用什么手段推动。** 见下面的约束库与出题流程。
- **强制关卡**：主神想推动某一步时，会设计一个"按正常途径必死"的局面，只留一个出口，而出口正是它要的那一步。死神来了2 就是：存活 5 天几乎不可能，打败张杰、完成队长考验的一刹那，整部片立即结束。
- **主神理由**：每个决定都附一段隐藏理由写进存档。它用于调试，也是智者推理的对象（"它为什么把我们扔进死神来了？"）。
- **原剧情模式**：主线任务和限制照原著（生化危机一就是 3h07m + 马修 100 米），**而原著的安排由议程状态解释**：上半部异常难，是因为张杰的半引导者异常让主神刻意加难（L5595），难度又按最强者张杰来定。玩家改变了走向时，主神按同一套议程逻辑应对，例如提早完成队长考验，异常就提早解除，后面的难度随之回落。
- **沙盒模式和原剧情里的"偏离"**：由主神 AI 出题导演生成——读取队伍画像（评价值，不含自创技能和基因锁），从**约束库**里挑约束、按队伍实力定参数（例：绑定半径 = 队伍在剧情节奏下勉强跟得上的距离；机动太高时不再用绑定，改为保护易碎目标或区域限制），优先压队伍最强、最依赖的维度，并放一个指向成长瓶颈的机会。引擎估算全灭率，必须落在目标区间并留一条轻松解法，否则打回重出。详见 `core-mechanics-analysis.md` 第 1.3~1.4 节。
- **标定**：拿原著的队伍状态喂给出题器，应能得到接近原著的约束（新人 → 100 米；三名开锁者 → 5000 米 + 团战），这是出题器的验收测试。

### 5.6 结算（奖励与相对难度挂钩）
- **固定项**：活过一部 1000 点；讲解规则 +100；扣分（杀新人 −1000、泄密每句 −10）。
- **击杀奖励** = 怪物基础价 × 相对威胁（怪物威胁 ÷ 击杀者的评价战力）。相对威胁过低时奖励归零。曲线用原著数字标定：爬行者 100（生化危机一）→ 50（生化危机二）→ 25（偷袭生化）；异形 500（异形一）→ 100（异形4）。
- **支线等级** = 这支队伍完成它的预计全灭率（D 简单 … B 约 80% … 双B ≥ 90%）。同一件事，队伍越强，给的等级越低。
- **特殊奖励**：如"精神临界值突破"+500 点并加属性。
- 点数为负就被抹杀。

### 6.2 交互流程（照原著）
1. **回归当晚不兑换**：原著惯例是先休息一晚，第二天上午在广场集合再协商。游戏里回归当晚只做结算和造人。
2. **结算**：奖励逐条"涌进脑海"，用逐行跳出的动画表现。
3. **（有队长后）先查下一部片**，再决定兑换什么。
4. **浏览与门槛核对**：点数、支线等级、前置强化（高一级需要先有同系低一级）、素质门槛（例：精神能量类技能要求精神力强化超过 3000，有天赋的角色例外）、能量类型（纳戒需要内力等）。不满足时，主神提示"自身无法兑换"并说明原因。
5. **支线拆分/合成**由玩家自己操作：1B = 3C，1C = 3D，3B = 1A（原文有"1C = 2D"的异说，按数值表取 3D）。
6. **交付表现**：身体强化是光柱罩身、悬浮、光粒入体；物品是光幕落下；技能卷轴是化烟、使用方法涌入脑海。
7. **适应与熟练度**：D/C/B 级即时生效；A 级以上内功、技能、血统兑换来的"只是心法"，需要训练才能发挥。游戏里新兑换的技能带一个**熟练度**，训练或实战使用后才逐步达到全额效果。

### 6.3 规则与限制
- **代兑**：可以用自己的点数给别人兑换物品或强化。**每人每部片只能给别人一次**点数或支线；复活集资算不算这一次，原著有争议，先按"不算"处理，留作可调开关。
- **不退换、不维修**：没有退货；主神只给物品重新充能，不修理，损坏的法器就报废。
- **绑定物品**：部分物品只有兑换者能用（认主武器、海贼成员绳）。
- **双血统风险**：同时持有两种血统有 70% 几率变成非人。主神会先警告，玩家坚持时按概率结算。
- **修复**：分"修补"（便宜，轻伤）和"修复"（贵，危及性命），以及基因修复（首次开锁后）。可以替别人付，"全体修复"可以由一人代付。结算后点数为负就被抹杀，所以玩家要留"保命余额"。
- **造人**：首个免费，之后 500 点；以人类为蓝本，最多约两倍常人素质，身高上限约 2.45 米；造不出异形、神，也造不出主神可兑换的血统。造物是活人，会自己行动；制造者死亡，造物随之消失。有队长之后，造物必须一同进片，或者用 1 个 D 级支线"赎身"。
- **主神提问**：规则类问题会回答（例："造出来的人是不是真的？""能不能同时选两种血统？"）；秘密类拒绝或不回应（恶魔/天神小队成员、首个造人名额的用途、主神空间的来历）。问答做成一本随剧情逐条解锁的**规则百科**。
- **新人**：新人直接在恐怖片里醒来，活过第一部才第一次进入主神空间；老手给新人讲规则 +100 点。

### 6.4 休整日 = 行动点
- 每次休整原著写死 10 天（实际有长有短，原剧情模式按原著每次的天数）。生化危机一之后是 9 天，第九天黄昏光柱降下。
- 兑换、结算、提问、造人**不耗天**；训练、对练、制造、度假**耗天**；出发前最后一天强制休息（原著惯例）。
- 去旧片或训练世界修炼时，主神空间"只过一瞬"，这是花点数买的"天数外"修炼（M3 起，回现实和旧片时引入）。

### 6.5 解锁顺序（原剧情与沙盒共用）
1. 开局：结算、六属性、基础兑换（D~B）、造人、房间、训练场、出发。
2. 第一次休整后：分级修复、规则百科、回上一部世界度假。
3. 出现科技人才后：零件和图纸页、工坊。
4. 累计 3 名开锁者：金色石碑出现，团战开启。
5. 第一次团战后：代兑与赠予、团队章程（可编辑的"中洲五条"、投票）。
6. 通过引导者考验：队长权限（推荐兑换、预知下一部片、恶魔/天神小队情报）、纪念石壁、造物入片与赎身规则、天神小队邀请（接受或拒绝的分支）。

### 6.6 人造人陪伴
（依据 `core-mechanics-analysis.md` 第七节）
- **造物是完整的 AI 角色**：人设来自制造时的设定；"按记忆复制"时，由玩家写下对那个人的记忆作为人设种子（原著里萝丽的记忆就来自郑吒）。
- **住在制造者的房间**，有心情和愿望：担心出征的人、想同行、想被需要、想看看现实世界；也会吃醋、会孤独。
- **陪伴行动**（耗休整天数）：聊天、约会、一起训练、教她技能、带她度假或回现实。对话由 AI 驱动，带长期记忆。关系数值：亲密、依赖、安心。
- **对制造者的影响**：休整期恐惧恢复更快；心魔检定时是"锚"。但她也是软肋：她受伤或死亡时，制造者恐惧暴涨，可能崩溃、黑化（偏向王者之道），也可能迎来突破。
- **成长**：主神强化、有限的训练、护具、后勤专长（医疗、烹饪、情报、驾驶），远征时占一个支援位；黑暗选项是用 TBD 改造成追踪者（战力大涨、意识空白）。
- **入片义务**：有队长之后必须一起进片，或者每部片花 1 个 D 级支线赎身。
- **死亡与重造**：可以花 500 点按制造者的记忆重造，但新造物只有制造者记得的部分，她自己的私人记忆没了（游戏规则，从原著"记忆来自制造者"推出）。
- **绑定**：制造者死亡，造物和房间一同消失；制造者复活，她也回来。
- **同一框架也用于**带入队伍的剧情人物（伊莫顿、安苏娜）和剧情生物（黑龙、骷髅梦魇）。
- **M1**：郑吒造萝丽、房间里的 AI 对话、心情与亲密度、她对出征的反应；见父母在 M3，入片义务和赎身在 M6，重造按需加入。

## 7. 经济、队伍与生死

### 7.1 两种货币
奖励点数，加分级的支线剧情（D < 双D < C < 双C < B < 双B < A < 双A < S < 双S）。**兑换价格以原著为锚点**（来源 `mechanics.md`，原文自相矛盾处按其第 10 章的处理建议）；奖励按 5.6 的相对难度规则计算。

### 7.2 兑换体系：大量、广泛取材、可控
- **规模**：M1 约 200 条（D~B）；完整版 2000 条以上（D~双S）；之后还有玩家向主神"许愿"的长尾条目，由主神 AI 现场生成。
- **取材**：像原著一样，广泛取材于各类作品、神话和科幻设定；分类结构是四大类 → 子类 → 系列 → 等级链（见 `core-mechanics-analysis.md` 4.2）。
- **效果积木**：每个兑换项由可执行的积木组成（属性加成、技能、能量池、被动触发、状态、标签、门槛、副作用），所以批量生成和 AI 生成的条目都真能用。
- **定价公式**：由积木算出价值，遵守原著规律（10 点 = 1 属性；无限弹药 ×20；魔法传说类 ≈ 科技类 ×2；前置链；双血统 70% 变异风险；有副作用打折）。**支线等级取积木里最高的档次**（反映效果的档次，不是总量：原著里精神力扫描 4000+C 折合价值反而高于蜘蛛侠基因 2000+B），**点数 = 价值 − 支线折算值**（D 500、C 1400、B 2400，由原著三件纯属性兑换项标定；A、S 暂无锚点）。**原著出现过的价格必须被公式算对**，这是定价公式的验收测试（计划 4 已锁住 23 件）。原著式评价分以后再加。
- **批量生产方式**：按系列 × 等级，由 AI 辅助生成数据、人工审核，数据文件按系列拆分，方便逐步扩充。

### 7.3 评价与难度
团队评价 = 完成过的片的难度 + 成员兑换属性的强弱；**自创技能和基因锁阶数不计入**（原著）。
- **评价的变化**：主神按"差一点就团灭"来安排每部片；活过一部本该团灭的片、损失又小，评价加一分；队长死亡扣分；**团灭清零**（所有人都死过，包括靠重生十字章复活的人），回到普通小队的难度，经历过的片的记录也消失（L8003~8006、L21846）。评价超过特殊小队时，主神会安排和它们对抗来验证。
- 评价决定奖励折算（5.6）、出题参数（5.5）、团战对手强度；评价看不到的真实战力，就是玩家的战略空间。

### 7.4 队友关系与内斗
（依据 `core-mechanics-analysis.md` 第八节。原著里主神本就希望各队"如同盅一样自相残杀"（L3084）；赵缀空的东美洲队团战先杀自己的新人（L13688），印洲队宁可自己杀自己人也不让对手得分（L4350）。）
- **关系网**：每两人之间有信任、好感、敬畏、怨恨，以及恋慕、仇敌、师徒、战友等标记，由事件改变（救命、并肩、被当诱饵、分配不公、见死不救……）。
- **个人倾向**：忠诚、野心、道德、求生欲、理念（伙伴之道 / 利益至上 / 强者为尊 / 只顾自己）。
- **凝聚力、派系、团队文化**：凝聚力由关系网汇总，决定服从（信任低的人转为 AI 控制、可能抗命）、投票、合击和心灵锁链的效果、救援意愿、恐惧传染、赠予意愿。
- **冲突升级阶梯**：不满 → 顶撞 → 抗命 → 擅自行动 → 私藏或偷窃 → 叛逃或转队 → 背刺谋杀（主神照扣 −1000）→ 内斗团灭。引擎按阈值推进，AI 负责具体表现。
- **团队章程**（可编辑的"中洲五条"，像政策卡）：新人入队要不要投票、资源怎么分、剧情物品谁保管、保护优先级、允不允许牺牲新人、内斗怎么惩罚。每条都改变凝聚力、效率和风险。
- **队长威信** = 敬畏 × 合法性；牺牲和诱饵决策会扣相关成员的信任，除非事先说服或事后补偿。
- **AI 队伍的文化**：东美洲（强者为尊、团战先杀新人）、印洲（涣散）、南炎洲（两派）、森洲和西海（圈养新人）、东海（民族主义加内讧）、恶魔（强者自由、队员是棋子）、天神（用谎言统治）。凝聚力低的队伍可以被挑拨、收买、招降、换情报。
- **特殊身份**：卧底、引导者、被精神控制的人可能混在新人里。
- **M1**：新人的信任与服从、牟钢的恐慌、扶不扶掉队者和留守还是跟走对信任的影响；诱饵、投票、决裂在 M2，章程在 M4，派系与叛逃逐步加深。

- 投票（中洲队传统）、团队章程、每片只能互赠一次点数或支线，随对应的片逐步实现（投票 M2、章程 M4）；关系网和凝聚力的数据模型在 F0 就建好。

### 7.5 复活（复活真经在 M4 出现，复活经济在下半部开端）
- 祭坛复活：有尸体 B + 7000 点，无尸体 B + 8000 点。
- 主神空间内复活：死者历来所得点数与支线的 2 倍。
- 首部就死的新人免费。
- 每人只能复活一次。

### 7.6 特殊小队
（依据 `core-mechanics-analysis.md` 第十节）
- **主神维护整个轮回世界的状态**：17 支普通队伍加两支特殊小队，各有课程阶段、队长、开锁者、文化、凝聚力，在后台粗粒度推进（团灭、队长去天神、成员被复制……）；队长权限可以看到一部分，作为"新闻"。
- **恶魔轮回小队 = 镜像生成器**：
  - 玩家角色潜力突升时（造人、凭自身属性开锁、心魔突破、顿悟……），主神可能做快照（属性、兑换物、点数、造物）复制进恶魔小队。
  - 复制体在后台过一段平行人生：在"恶魔心肠"的环境里受欺压、反抗、黑化，成长率更高。经历由 AI 生成，数值成长由引擎给出。
  - 之后作为宿敌出现，带着你当初的选择。
  - 原剧情按原著：复制体郑吒、复制体楚轩、复制体铭烟薇、复制体罗甘道、赵缀空的复制体等。
- **天神小队**：成为队长时收到邀请。接受 = 角色离队；原队换新引导者从头再来，新队长只有信息查询权（原著规则），往往从此衰落。扮演个人模式下这是一条真能走下去的分支。后期天神小队组建"天使联盟"，对抗恶魔小队。
- **出场**：主神按议程把特殊小队放进别队的片里，作为对照实验或加压手段（生化危机二、魔戒、最终一战）。
- **养殖队**是部分队伍自选的策略，不是主神设计的；主神对其团队评价不高。

### 7.7 失败的代价与重建篇
（依据 `core-mechanics-analysis.md` 第十一节）
- **代价分层**：
  - 一次扣分：点数、支线，结算为负即抹杀；
  - 任务失败：按规定扣分或抹杀；
  - 个人死亡：永久，除非付复活代价，且每人一次；
  - 队长真正死亡：职务解除，失去预知和查询权限，评价减分，要等新的引导者再考验；
  - 团战落败：负分**由幸存者承担**，对手拿走击杀奖励而变强；
  - 团灭（有人活下来）：以上全部，加评价清零、记录消失；
  - 全灭：这一代中洲队终结，只有纪念石壁留下。
- **代价跨越很多部片持续生效**：生化危机二团灭之后，郑吒独自扛下 −8000 的负分，独自回神鬼传奇挖复活真经，花了大约六部片才把人复活齐；而这次团灭用掉了几乎所有人唯一的复活机会，所以之后的死亡（罗甘道、最终一战）都是永久的。
- **重建篇**：只要还有一个人活着，团灭就不是游戏结束，而是进入一段新剧情。幸存者扛负分 → 评价清零、回到普通课程 → 找复活手段 → 一个个凑钱复活，决定先救谁，在复活和变强之间取舍 → 期间独自或带着剧情人物盟友闯片。
- **全灭**：这一代人的故事结束，纪念石壁留下名字；可以作为新一代中洲队继续（新的新人、新的引导者），之前的石壁还立在广场上。原剧情模式里这是"坏结局"分支；沙盒里是正常的世代更替。
- **成功也有代价**：一直赢，评价一直涨，主神就"全力培养，也即不停加大难度"（L8005），没有喘息的成长窗口。
- **原剧情的分支**：原著生化危机二是团灭，下半部走的是"失败之后"的线。玩家如果没有团灭，下半部按议程逻辑走另一条线（评价不清零、主神持续加码），这条线要另行推演。
- **存档**：推荐铁人模式（一个存档，失败就是失败）；另给想体验剧情的人一个宽松选项。

## 8. 模式支持（架构层）

- **控制器抽象**：每个单位挂一个控制器，玩家控制器或 AI 控制器（由大模型按人物的背景、性格、心魔、记忆做决策）。"扮演整队"就是玩家控制所有愿意服从的成员，"扮演个人"就是只控制一人，其他人由 AI 接管，队伍决策走投票或听队长命令。
- **剧本来源抽象**：恐怖片内容可以来自手写剧本（原剧情），也可以来自主神 AI 出题导演（沙盒和原剧情里的偏离）。两者产出同一种数据结构：地点图 + 事件表 + 敌人池 + 任务与约束。
- M1 实现手写剧本、玩家控制器，以及 AI 驱动的剧情人物、新人对话和主神问答；战斗里的逐回合行动仍用确定性的效用 AI（见 8.1）。

### 8.1 AI 接管（主神与 NPC）
（详见 `core-mechanics-analysis.md` 第五节）
- **原则：AI 提议，规则引擎裁决。** 数值、合法性、生死归引擎；AI 负责判断、对话、创作，只输出结构化"意图"（一句台词、从合法行动列表里选一项、一条任务约束、一个兑换项方案），引擎校验后才执行。
- **主神 AI**：维护议程（课程阶段、异常、潜力、实验分组），并据此决策，每个决定附隐藏理由；规则问答（秘密分级，按进度解锁，不该说的就拒绝）、出题导演、结算宣读（数字由引擎算）、兑换许愿（自然语言 → 效果积木方案 → 引擎定价校验）、片中干预（从约束库里选）。主神的语气照原著："死板但庄严""不带一丁点感情波动"。
- **NPC AI**：
  - 剧情人物：按人设对玩家的话和行为作出反应，比如能不能说服马修、火焰女皇吃不吃威胁。关键说服由 AI 评估玩家的论点，给出"说服力等级"，再由引擎做检定。
  - 队友与新人：性格驱动的发言、投票、服从或抗命、崩溃时的表现。
  - 其他轮回小队队长：谈判、结盟、欺骗、伏击。
  - 重要敌人：开战时由 AI 定战术方针。
- **对话输入**：PC 上可以自由打字；手机上默认给出 AI 生成的 3~4 个候选回复，也可以打字或语音输入。
- **模型服务（已确认）**：接入层可切换服务商，同时支持 Anthropic 和 OpenAI 兼容两种接口；在游戏设置里填写地址、密钥和各档模型名；默认指向你现有的自建网关。PC 和手机都通过网络调用。
- **模型分档**：出题、许愿、对手队长这类低频高价值的决策用强模型；NPC 日常对话用快而便宜的模型。两档都可以在设置里分别指定。
- **上下文与记忆**：世界设定库（全书摘要、机制百科、主神功能清单、核心机制分析）作为静态前缀，用提示缓存；每个重要 NPC 有记忆摘要，随存档保存。
- **延迟**：对话流式输出；出题这类重活在休整期或转场时预先生成。
- **离线兜底**：没有网络时，原剧情模式退回原著脚本台词和固定选项，沙盒退回规则化的出题器。
- **可复现**：AI 输出写进存档，读档不会重新调用。

### 10.2 分层原则
- **core 层**是纯逻辑：输入是游戏状态和玩家决策，输出是新状态和一串事件（"某某受到 30 伤害""马修获救"）。core 不碰节点和画面，所以能在无界面模式下测试，也能跑战斗模拟做平衡。
- **ui 层**只订阅事件来播放动画、显示文本，并把玩家选择交回 core。
- **data 层**用 JSON 存全部内容，加载时做格式校验；以后扩内容（新电影、新兑换项）主要是加数据，不改代码。
- 随机数统一用带种子的生成器，存档里记录种子，方便复现 bug。
- **ai 层**只和 core 交换"意图"和"状态摘要"：core 给出可选行动列表和局面摘要，ai 层返回所选意图，core 校验后执行。ai 层可以整体替换成脚本兜底实现，这也是测试时的默认实现。

### 10.3 交互与分辨率
- 基准分辨率 1920×1080，横屏，`canvas_items` 拉伸，保持宽高比。
- 所有可点元素在手机上的触控尺寸 ≥ 48dp；没有悬停时，长按显示详情。
- 文本全中文，从一开始就走 Godot 翻译表，为以后多语言留口。

### 10.4 测试
- 用一个自写的轻量测试脚本，通过 `godot --headless` 运行 `tests/`。
- 规则测试：伤害公式、CTB 顺序、支线换算、兑换前置、结算数字（用原著的例子做断言，比如首战 6502 点 = 1000 + 5000 + 500 + 2）。
- 战斗模拟：AI 对 AI 跑 N 场，输出胜率和平均回合数，用于平衡。

### 10.5 环境准备（列为任务）
- 安装 Godot 4.7.2 导出模板。
- 安卓导出需要 JDK 17（本机只有 JDK 8），安卓 SDK 已在本机。
- 项目用 git 管理，Codex 的改动通过 diff 审查（需要你同意后初始化仓库）。

## 11. 美术规格（像素玩法画面 + 动漫剧情插图）

- **两套画风，按用途分开**（2026-11-06 定）：
  - **玩法画面全部用像素**：战斗、地点探索、主神空间。人物是 Q 版像素小人，简单直观，好画，也好做动作。
  - **只有剧情用日系动漫插画**：对话立绘、关键剧情插图、过场。对话时立绘叠在当前的像素画面上（画面压暗）；关键时刻换成整张插图。
- **像素画面**：
  - 内部分辨率 480×270，用 SubViewport 整数放大 4 倍到 1920×1080；最近邻采样，像素对齐，不做非整数缩放。
  - 界面、文字、立绘、插图不进像素层，按 1920×1080 原生分辨率绘制，保证中文清晰。
  - 整体偏暗、偏冷。恐怖感靠场景、光照（黑暗、手电光圈）、颗粒和暗角后处理；小人可爱不要紧，压迫感主要来自剧情和死亡。
- **过场**：一张张剧情插图，加上 Godot 的推拉、摇移、震屏、闪白和转场，像视觉小说或漫画分镜；不做真正的动画片段。
- **资源类型与规格**

| 类型 | 尺寸 | 说明 |
|---|---|---|
| 战斗小人（我方、人形敌人） | 人物约 32px 高，Q 版 2~3 头身；单帧画布 48×48，透明 | 侧视，我方朝右、敌方朝左；待机、攻击、受击、倒地（或死亡）四个动作，每个 2~6 帧 |
| 大型敌人 | 按体型 48~128px，透明 | 动作同上；舔食者、暴君这类可以占多格 |
| 像素场景 | 480×270，不透明 | 战斗背景、地点探索画面、主神空间各处 |
| 像素图标 | 16×16 或 24×24，透明 | 技能、道具、状态 |
| 角色立绘 | 1024×1536，透明 | 对话用；主要角色 3~4 种表情（平静、恐惧、愤怒、受伤） |
| 剧情插图 | 1920×1080，不透明 | 关键剧情时刻、过场分镜 |

- **一致性策略**：每个角色先出一张动漫设定图（正面全身），写入 `docs/art/characters.md` 作为固定描述。立绘以设定图为参考；像素小人也从设定图转出，保留在 32px 下还看得出来的特征（发型、发色、服装配色、标志性物件）。动漫图共用一段风格前缀提示词；像素图另用一段像素前缀和一套共用调色板。
- **生图工具**：Codex 用本机的 sprite-gen 技能。像素图走 `gen --provider codex` 生成，再用 pixel-unfake 对齐到真正的像素格子（统一格子、统一调色板）；**不用 `pixel-draw`**（它走 Claude 订阅额度，用户决定不用）。透明边缘不干净时用 `sprite-gen cutout`，不另写抠图脚本。
- **图片不进仓库**：仓库是公开的，图片（AI 生成的同人图）只在本机保留并定期备份；仓库只存提示词、生成报告和 SHA-256 校验和，别人可以照着重新生成。最终成品放 `game/art/`，原图和中间文件放仓库根目录的 `art_src/`（不在 Godot 工程里，不会被打包）。
- **战斗背景构图**：横向宽景、偏侧视，画面下方约 40% 是平整开阔的地面，留给双方三排站位；陷阱、激光这类会动的危险不画进背景，由 Godot 做成单独的效果层。
- **试验记录**：任务卡 001、001b 定下了动漫画风（郑吒设定图、两张立绘、丧尸都通过）。任务卡 002 试了动漫逐帧战斗动画，结论是 AI 画的逐帧动作前后对不上，不可行；这也是战斗改用像素小人的原因之一。任务卡 003 的像素风格试验（Q 版郑吒、丧尸、走廊背景、对话叠立绘）用户已认可，作为批量生产的基线。

## 12. Claude × Codex 协作流程

1. **分工**：Claude 负责 `core/`、`data/`、剧本、测试和规格文档；Codex 负责 `ui/` 场景、美术生成、特效、音频接入、导出配置、抠图之类的工具脚本。双方都读 `docs/`。
2. **任务卡**：放在 `docs/codex-tasks/NNN-标题.md`，内容包括：目标、要先读的文件、**允许修改的文件范围**、要对接的接口（信号、函数）、验收标准（截图或测试）、完成后的汇报格式。
3. **流程**：Claude 写任务卡 → 你把任务卡交给 Codex → Codex 在本项目目录里完成，并按格式在任务卡末尾写汇报 → 你告诉 Claude "某号任务完成" → Claude 看 diff 和汇报，审查、修正或写下一张卡。
4. **防冲突**：同一时间同一组文件只有一方在改；任务卡的"允许修改范围"就是边界。
5. **`AGENTS.md`**：写明代码风格、目录约定、"不要改 core/ 和 data/ 的格式"等规则，Codex 每次都会读取。

## 13. 风险

| 风险 | 应对 |
|---|---|
| 生图风格不一致 | 先做风格试验；设定图 + 固定前缀；战斗用像素小人，比大图逐帧动画好控制，像素图统一格子和调色板 |
| 范围过大 | 严格按里程碑推进；一部片打磨完再做下一部 |
| 原著数值后期膨胀（核弹级） | 数值曲线按片区段缩放；原剧情模式下前中期严格照原著，后期另行设计 |
| 安卓工具链 | 先在 PC 上完成 M1；JDK 17 和导出模板列为前置任务 |
| 手动协调 Codex 的往返成本 | 任务卡尽量自包含、一次完成；必要时改为由 Claude 直接调用 `codex exec` |
| AI 成本与延迟 | 模型分档、提示缓存、预生成、流式输出；每局统计调用量 |
| 运行时才出现的角色没有立绘（玩家造的人、沙盒新人、许愿出的物品） | **已确认**：开发时由 Codex 批量生成立绘库（几百张，覆盖不同年龄、性别、职业、气质）、对应的像素小人库和图标库，按设定自动匹配；设置里可开启运行时生图，给重要角色（如玩家造的人）生成专属立绘，走同一个可切换的 AI 网关；断网时用库里的图 |
| AI 说乱规则或剧透 | "AI 提议，引擎裁决"；主神秘密分级；输出必须通过格式和规则校验 |
| 断网（尤其手机） | 脚本兜底全程可玩；AI 输出写入存档 |
| 兑换条目多了失衡 | 效果积木 + 定价公式 + 平衡上限；战斗模拟回归测试 |
