## 设计要点

- **三个槽，不无限存**：铁人模式的取舍——随时能存，但只有三个位，覆盖就是覆盖。
- **摘要不加载剧本**：标题画面只读存档 JSON 的顶层（phase / day / expedition.clock / 郑吒点数 / 文件时间），`Session.load_from` 只在真正读档时调用。
- **槽位文案**：远征中显示"生化危机一 · 第 X 分钟"，刚回归显示"刚回归 · 待结算"，休整显示"主神空间 · 第 X 天"，结束显示"第一部结束"，空槽显示"空"。
- **设置只有两项**：窗口（窗口/全屏）与主音量。`Settings.apply()` 在 `DisplayServer.get_name() == "headless"` 时直接返回，所以无头测试不会碰引擎。
- **Esc 的优先顺序**：标题画面先关覆盖层（设置/存档）→ 游戏里先关对话框 → 再关暂停菜单 → 都没有才打开暂停菜单。Esc 在标题画面不退出游戏。
- **键盘**：远征界面 `1~9` 直接选当前待选项；选项按钮的文字不变，`press_choice(id)` 仍是唯一入口。
- **顶栏**：标题画面隐藏，进游戏显示"无限恐怖 + 状态 + 菜单（Esc）"；内容区在标题时是 1920×1080，游戏里是 1920×1024（下移 56px）。
- **退出**：走 `get_tree().quit()`，标题与暂停菜单各有一个入口。

**不在本计划范围**：读档确认框（覆盖存档不二次确认）、无限存档位、云存档、键位自定义、手柄、音频资源本身（现在没有音效，音量设置先接上 Master 总线）。

```gdscript
extends RefCounted
## 存档槽：三个位，文件在 user://save_1.json ~ user://save_3.json（铁人模式不做无限存档）。
## 标题画面只要摘要，所以 summary() 直接读 JSON 顶层，不重建 Session（不然每次开标题都要加载剧本）。

const SaveService = preload("res://core/save/save_service.gd")
const Session = preload("res://core/session/session.gd")

const COUNT := 3
const FILE_FORMAT := "user://save_%d.json"


static func path(slot: int) -> String:
	return FILE_FORMAT % slot


static func valid(slot: int) -> bool:
	return slot >= 1 and slot <= COUNT


static func write(slot: int, session: RefCounted) -> Error:
	if not valid(slot) or session == null:
		return ERR_INVALID_PARAMETER
	return SaveService.write_dict(path(slot), session.to_dict())


## 读不到或坏了返回 null。
static func read(slot: int) -> RefCounted:
	if not valid(slot):
		return null
	return Session.load_from(path(slot))


static func erase(slot: int) -> void:
	if not valid(slot):
		return
	if FileAccess.file_exists(path(slot)):
		DirAccess.remove_absolute(ProjectSettings.globalize_path(path(slot)))


## 标题/暂停菜单用：{"slot", "exists", "phase", "day", "clock", "label", "points", "saved_at"}。
static func summary(slot: int) -> Dictionary:
	if not valid(slot):
		return {"slot": slot, "exists": false, "label": "无效存档位"}
	var d := SaveService.read_dict(path(slot))
	if d.is_empty():
		return {"slot": slot, "exists": false, "label": "空"}
	var ex: Dictionary = d.get("expedition", {})
	return {
		"slot": slot,
		"exists": true,
		"phase": String(d.get("phase", "")),
		"day": int(d.get("day", 0)),
		"clock": int(ex.get("clock", 0)),
		"outcome": String(ex.get("outcome", "")),
		"label": _label(d),
		"points": _points(d),
		"saved_at": _time_text(slot),
	}


static func all_summaries() -> Array[Dictionary]:
	var out: Array[Dictionary] = []
	for i in range(1, COUNT + 1):
		out.append(summary(i))
	return out


static func _label(d: Dictionary) -> String:
	var ex: Dictionary = d.get("expedition", {})
	match String(d.get("phase", "")):
		"expedition":
			return "生化危机一 · 第 %d 分钟" % int(ex.get("clock", 0))
		"settlement":
			return "刚回归 · 待结算"
		"hub":
			return "主神空间 · 第 %d 天" % int(d.get("day", 0))
		"done":
			return "第一部结束"
	return "未知进度"


## 郑吒的点数，给标题画面一点进度感；没有就返回 -1。
static func _points(d: Dictionary) -> int:
	var game: Dictionary = d.get("game", {})
	var chars: Dictionary = game.get("characters", {})
	if not chars.has("zheng_zha"):
		return -1
	return int((chars["zheng_zha"] as Dictionary).get("points", -1))


static func _time_text(slot: int) -> String:
	var t := int(FileAccess.get_modified_time(path(slot)))
	if t <= 0:
		return ""
	var d := Time.get_datetime_dict_from_unix_time(t)
	return "%02d-%02d %02d:%02d" % [int(d["month"]), int(d["day"]), int(d["hour"]), int(d["minute"])]
```

- [ ] **Step 5：创建 `game/core/settings/settings.gd`**

```gdscript
extends RefCounted
## PC 端设置：窗口模式与主音量。存 user://settings.json，读不到或坏了就用默认值。
## apply() 只在有窗口的时候动引擎；无头跑测试时直接返回，避免 DisplayServer 报警。

const PATH := "user://settings.json"
const MODES: Array[String] = ["windowed", "fullscreen"]


static func defaults() -> Dictionary:
	return {"window_mode": "windowed", "volume": 0.8}


static func load_settings(path: String = PATH) -> Dictionary:
	var s := defaults()
	if not FileAccess.file_exists(path):
		return s
	var json := JSON.new()
	if json.parse(FileAccess.get_file_as_string(path)) != OK:
		return s
	var data: Variant = json.data
	if not data is Dictionary:
		return s
	if MODES.has(String(data.get("window_mode", ""))):
		s["window_mode"] = String(data["window_mode"])
	if data.has("volume"):
		s["volume"] = clampf(float(data["volume"]), 0.0, 1.0)
	return s


static func save_settings(s: Dictionary, path: String = PATH) -> Error:
	var f := FileAccess.open(path, FileAccess.WRITE)
	if f == null:
		return FileAccess.get_open_error()
	f.store_string(JSON.stringify(s, "\t"))
	f.close()
	return OK


## 窗口模式：windowed / fullscreen；音量：0~1 的线性值，转成分贝给 Master 总线。
static func apply(s: Dictionary) -> void:
	if DisplayServer.get_name() == "headless":
		return
	var mode := DisplayServer.WINDOW_MODE_FULLSCREEN if String(s.get("window_mode", "windowed")) == "fullscreen" else DisplayServer.WINDOW_MODE_WINDOWED
	DisplayServer.window_set_mode(mode)
	var v := clampf(float(s.get("volume", 0.8)), 0.0, 1.0)
	AudioServer.set_bus_mute(0, v <= 0.0)
	AudioServer.set_bus_volume_db(0, linear_to_db(maxf(v, 0.0001)))


## 改一项并立刻应用，返回新的设置（调用方负责再存盘）。
static func with_value(s: Dictionary, key: String, value: Variant) -> Dictionary:
	var out := s.duplicate()
	out[key] = value
	apply(out)
	return out
```

## 已知风险与缓解

- **存档覆盖不二次确认**：点"槽 1"就直接覆盖。三个槽本来就少，误覆盖代价大；下一版加确认框。
- **读档不做版本迁移**：`Session.VERSION` 变了就读不出来（返回 null，标题画面点了没反应）。现在版本没变过，等真要改结构时再写迁移。
- **设置在无头下不生效**：`apply()` 直接返回，所以无头验收只能验证字典读写，验证不了窗口真的全屏。真机手点一遍确认。
- **音量改的是 Master 总线**：现在还没有 AudioStreamPlayer，等音效进来后要确认 Bus 布局（音乐/音效分轨时这里要改）。
- **Esc 在标题画面不退出**：想退出要点"退出游戏"。这是有意的，避免误触。
- **数字键只在远征的"等选择"时生效**：战斗与对话里不抢按键，避免和输入框冲突。
