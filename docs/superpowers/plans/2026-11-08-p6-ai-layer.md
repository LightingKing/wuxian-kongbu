# 计划 6：AI 接入层 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `game/ai/` 做出 AI 接入层：可切换的服务商（Anthropic Messages API / OpenAI 兼容网关 / 离线）、两档模型、请求组装与响应解析（含提示缓存、结构化输出、拒答处理）、AI 意图的格式与校验（AI 提议、引擎裁决）、人设与记忆、世界设定库、离线兜底、AI 输出记录（读档不重新调用）、真实的 HTTP 传输层和流式输出解析。全部能在不联网的情况下测试。

**Architecture:** 按设计规格 10.2，ai 层只和 core 交换"任务"和"意图"：core 交来一个任务（局面摘要 + 合法选项），`ai_service.gd` 返回一个经过 `intents.gd` 校验的意图，来源是 ai、fallback 或 replay。服务商差异集中在 `providers.gd` 的两个纯函数里（组装请求、解析响应）。传输层是可替换的对象：真实的是 `http_transport.gd`（一个 Node），测试用假的。

**Tech Stack:** Godot 4.7.2（GDScript），Anthropic Messages API（原始 HTTP，GDScript 没有官方 SDK），OpenAI 兼容的 Chat Completions 接口。

## 设计要点

- **设置**（`ai_settings.gd`）：存在 `user://ai_settings.json`（Windows 上是 `%APPDATA%\Godot\app_userdata\无限恐怖\ai_settings.json`），不进仓库，因为里面有密钥。`provider` 是 `anthropic`、`openai_compatible` 或 `offline`。两档模型：`strong`（`claude-opus-5-5`，effort high，用于出题、许愿、对手队长）、`fast`（`claude-haiku-5-5`，effort low，用于 NPC 日常对话）。Anthropic 没填密钥时读环境变量 `ANTHROPIC_API_KEY`。没配置就全部走离线兜底。
- **Anthropic 请求**（`providers.gd`）：`POST {base_url}/v1/messages`，头 `x-api-key`、`anthropic-version: 2026-10-21`。`system` 分两块：第一块是静态的世界设定，带 `cache_control`（提示缓存要求前缀逐字节不变，所以变化的人设和局面放在第二块）。`output_config` 带 `effort` 和 `format`（按意图的 JSON Schema 结构化输出）。strong 档默认开服务端拒答回退（`fallbacks: "default"` + 头 `anthropic-beta: server-side-fallback-2026-07-01`）；fast 档（Haiku）没有服务端回退，不发。不发 `temperature`，也不发 `thinking`（这两个模型省略时就是自适应思考）。响应只读 `text` 块；`stop_reason` 为 `refusal` 算拒答，`max_tokens` 算截断。
- **OpenAI 兼容请求**：`POST {base_url}/chat/completions`（base_url 填到 `/v1`），`Authorization: Bearer`（没有密钥就不发）；世界设定和人设合成一条 system 消息；不发结构化输出参数（各家网关不统一），靠提示要求只输出 JSON，再宽松解析。`finish_reason` 为 `content_filter` 算拒答，`length` 算截断。
- **意图**（`intents.gd`）：五种——`npc_line`（台词）、`choose`（从合法选项里选）、`persuade`（说服力等级 0~3，引擎再做检定）、`zhushen_answer`（主神回答，透露禁止的关键词算不合格）、`replies`（2~4 句候选回复）。`extract_json` 容忍代码块和多余文字；`validate` 检查字段、范围、合法性，只保留规定的字段。
- **人设与记忆**（`persona.gd`）：人设来自 `data/ai/personas.json`（先放主神和马修两个样例，M1 的完整角色在计划 7）；记忆最多 12 条，超出时把最早两条合并（截到 120 字）。
- **世界设定库**（`lore.gd`）：`ai/lore/world_rules.json`（用 JSON 而不是 Markdown，导出时会被打包），拼成一段固定的文字。
- **离线兜底**（`fallback.gd`）：每种意图都有确定的规则；同一个任务 id 总是同样的结果；兜底的输出本身也能通过意图校验。
- **记录与回放**（`ai_log.gd`）：每个任务 id 的结果（不管来自 AI 还是兜底）都记下来，跟存档一起保存；同一个任务再问一次直接用记录，读档不会重新调用模型。
- **服务**（`ai_service.gd`）：记录 → 离线 → 发请求 → 解析 → 校验 → 合格就用，否则兜底并记下原因（传输错误、HTTP 错误、拒答、截断、输出不合格）。
- **传输层**（`http_transport.gd`）：用 `HTTPRequest` 发一次 POST；节点不在场景树里时直接回调 `not_in_tree`。
- **流式输出**（`sse.gd`）：解析两家的 Server-Sent Events，数据可以在任意位置被切开。传输层的流式读取等计划 8 做对话界面时再接上。

**关于 OpenAI 兼容接口**：Anthropic 的官方建议是直接用 Anthropic 接口；这里保留 OpenAI 兼容是设计规格里已确认的需求（接你自己的网关）。两种都能用，设置里切换。

**不在本计划范围**：在剧情和休整里真正发起这些任务（计划 7）；对话界面、流式逐字显示、手机上的候选回复按钮（计划 8）；主神出题和许愿这两类复杂任务（它们要用到效果积木和约束库，等内容和界面齐了再加）；用量统计和费用显示。

```gdscript
extends RefCounted
## AI 服务设置（设计规格 8.1"模型服务""模型分档"）。存在 user://ai_settings.json，不进仓库（里面有密钥）。
## provider：anthropic（Anthropic Messages API）、openai_compatible（OpenAI 兼容网关）或 offline（不联网，全部走脚本兜底）。
## base_url：anthropic 填到域名为止（https://api.anthropic.com），请求发到 base_url + "/v1/messages"；
##           openai_compatible 填到 /v1 为止（例如 https://你的网关/v1），请求发到 base_url + "/chat/completions"。
## 两档模型：strong 用于出题、许愿、对手队长这类低频高价值的决策；fast 用于 NPC 日常对话。
## provider 是 anthropic 且 api_key 为空时，读环境变量 ANTHROPIC_API_KEY。

const PATH := "user://ai_settings.json"


static func defaults() -> Dictionary:
	return {
		"provider": "anthropic",
		"base_url": "https://api.anthropic.com",
		"api_key": "",
		"timeout_seconds": 60,
		"tiers": {
			"strong": {"model": "claude-opus-5-5", "effort": "high", "max_tokens": 16000, "fallbacks": true},
			"fast": {"model": "claude-haiku-5-5", "effort": "low", "max_tokens": 4096, "fallbacks": false},
		},
	}


## 读设置：文件里的值覆盖默认值（tiers 按档合并）；文件不存在或坏了就用默认值。
static func load_settings(path: String = PATH) -> Dictionary:
	var s := defaults()
	if not FileAccess.file_exists(path):
		return s
	var json := JSON.new()
	if json.parse(FileAccess.get_file_as_string(path)) != OK:
		return s
	var parsed: Variant = json.data
	if not parsed is Dictionary:
		return s
	for k: String in parsed:
		if k == "tiers" and parsed[k] is Dictionary:
			for tier: String in parsed[k]:
				var merged: Dictionary = (s["tiers"].get(tier, {}) as Dictionary).duplicate()
				merged.merge(parsed[k][tier], true)
				s["tiers"][tier] = merged
		else:
			s[k] = parsed[k]
	return s


static func save_settings(s: Dictionary, path: String = PATH) -> Error:
	var f := FileAccess.open(path, FileAccess.WRITE)
	if f == null:
		return FileAccess.get_open_error()
	f.store_string(JSON.stringify(s, "\t"))
	f.close()
	return OK


## 实际使用的密钥：设置里的，或者（anthropic 时）环境变量。
static func api_key(s: Dictionary) -> String:
	var key := String(s.get("api_key", ""))
	if key == "" and s.get("provider", "") == "anthropic":
		key = OS.get_environment("ANTHROPIC_API_KEY")
	return key


## 能不能联网调用：offline 不行；没有地址不行；anthropic 必须有密钥（OpenAI 兼容网关可以不要密钥）。
static func is_configured(s: Dictionary) -> bool:
	var provider := String(s.get("provider", "offline"))
	if provider == "offline" or String(s.get("base_url", "")) == "":
		return false
	if provider == "anthropic":
		return api_key(s) != ""
	return provider == "openai_compatible"
```

extends RefCounted
## 服务商适配：把一次 AI 调用组装成 HTTP 请求，再把 HTTP 响应解析成文字。纯函数，不联网，方便测试。
## Anthropic（Messages API，接口版本 2026-10-21）：
##   - system 分两块：第一块是静态的世界设定，带 cache_control（提示缓存）；第二块是人设、记忆和局面（每次不同，放在缓存之后）；
##   - output_config：effort（思考深度），以及要求按 JSON Schema 输出（结构化输出）；
##   - strong 档默认开服务端拒答回退（fallbacks: "default"，beta 头 server-side-fallback-2026-07-01）；fast 档（Haiku）没有服务端回退，不发；
##   - 不发 temperature（这个接口版本已不接受）；
##   - 只读 type 为 text 的内容块（思考块等跳过）；stop_reason 为 refusal 算失败，max_tokens 算输出被截断。
## OpenAI 兼容：/chat/completions，system 合成一条消息；finish_reason 为 content_filter 算拒答，length 算截断。

const ANTHROPIC_VERSION := "2026-10-21"
const FALLBACK_BETA := "server-side-fallback-2026-07-01"

const AiSettings = preload("res://ai/ai_settings.gd")


## 返回 {"url": String, "headers": PackedStringArray, "body": String, "timeout": float}
static func build_request(s: Dictionary, tier: String, lore: String, context: String, prompt: String, schema: Dictionary) -> Dictionary:
	var t: Dictionary = s["tiers"][tier]
	var base := String(s["base_url"]).rstrip("/")
	var key := AiSettings.api_key(s)
	var headers := PackedStringArray(["Content-Type: application/json"])
	var body := {}
	var url := ""
	if s["provider"] == "anthropic":
		url = base + "/v1/messages"
		headers.append("x-api-key: " + key)
		headers.append("anthropic-version: " + ANTHROPIC_VERSION)
		var output_config := {"effort": String(t["effort"])}
		if not schema.is_empty():
			output_config["format"] = {"type": "json_schema", "schema": schema}
		body = {
			"model": String(t["model"]),
			"max_tokens": int(t["max_tokens"]),
			"system": [
				{"type": "text", "text": lore, "cache_control": {"type": "ephemeral"}},
				{"type": "text", "text": context},
			],
			"messages": [{"role": "user", "content": prompt}],
			"output_config": output_config,
		}
		if bool(t.get("fallbacks", false)):
			body["fallbacks"] = "default"
			headers.append("anthropic-beta: " + FALLBACK_BETA)
	else:
		url = base + "/chat/completions"
		if key != "":
			headers.append("Authorization: Bearer " + key)
		body = {
			"model": String(t["model"]),
			"max_tokens": int(t["max_tokens"]),
			"messages": [
				{"role": "system", "content": lore + "\n\n" + context},
				{"role": "user", "content": prompt},
			],
		}
	return {"url": url, "headers": headers, "body": JSON.stringify(body), "timeout": float(s.get("timeout_seconds", 60))}


## 返回 {"ok": bool, "text": String, "error": String}
static func parse_response(provider: String, status: int, body: String) -> Dictionary:
	var json := JSON.new()
	var data: Variant = json.data if json.parse(body) == OK else null
	if status != 200:
		var msg := ""
		if data is Dictionary and data.get("error") is Dictionary:
			msg = String(data["error"].get("message", ""))
		return {"ok": false, "text": "", "error": "http_%d %s" % [status, msg]}
	if not data is Dictionary:
		return {"ok": false, "text": "", "error": "bad_json"}
	if provider == "anthropic":
		var stop := String(data.get("stop_reason", ""))
		if stop == "refusal":
			return {"ok": false, "text": "", "error": "refusal"}
		if stop == "max_tokens":
			return {"ok": false, "text": "", "error": "truncated"}
		var parts: Array[String] = []
		for block: Dictionary in data.get("content", []):
			if block.get("type", "") == "text":
				parts.append(String(block.get("text", "")))
		return {"ok": true, "text": "".join(parts), "error": ""}
	var choices: Array = data.get("choices", [])
	if choices.is_empty():
		return {"ok": false, "text": "", "error": "no_choices"}
	var finish := String(choices[0].get("finish_reason", ""))
	if finish == "content_filter":
		return {"ok": false, "text": "", "error": "refusal"}
	if finish == "length":
		return {"ok": false, "text": "", "error": "truncated"}
	var message: Dictionary = choices[0].get("message", {})
	return {"ok": true, "text": String(message.get("content", "")), "error": ""}

```gdscript
extends RefCounted
## AI 意图（设计规格 8.1"AI 提议，规则引擎裁决"）：AI 只输出结构化的意图，引擎校验后才执行。
## 任务（task）是 core 交给 AI 层的一份请求，字段：
##   id（稳定的编号，用于回放）、kind（下面五种之一）、tier（"fast" / "strong"）、situation（局面摘要）
##   choose / replies：options = [{"id", "text"}]；persuade：argument（玩家的说辞）、goal（想让对方做什么）；
##   zhushen_answer：question（提问）、forbidden（不能透露的关键词）。
## 五种意图：
##   npc_line        {"say": 台词}
##   choose          {"choice": 选项 id, "say": 台词（可空）}
##   persuade        {"level": 0~3, "reason": 理由}      说服力等级：0 无效、1 弱、2 中、3 强，由引擎再做检定
##   zhushen_answer  {"answer": 回答, "refuse": bool}    回答里出现 forbidden 关键词算不合格
##   replies         {"replies": [2~4 句候选回复]}        手机上给玩家选

const KINDS: Array[String] = ["npc_line", "choose", "persuade", "zhushen_answer", "replies"]
const MAX_SAY := 200
const MAX_REPLY := 60


## 发给 Anthropic 结构化输出的 JSON Schema（所有 object 都要 additionalProperties: false；范围限制不写进 schema，由 validate 检查）。
static func schema(kind: String) -> Dictionary:
	var props := {}
	var required: Array = []
	match kind:
		"npc_line":
			props = {"say": {"type": "string"}}
			required = ["say"]
		"choose":
			props = {"choice": {"type": "string"}, "say": {"type": "string"}}
			required = ["choice", "say"]
		"persuade":
			props = {"level": {"type": "integer"}, "reason": {"type": "string"}}
			required = ["level", "reason"]
		"zhushen_answer":
			props = {"answer": {"type": "string"}, "refuse": {"type": "boolean"}}
			required = ["answer", "refuse"]
		"replies":
			props = {"replies": {"type": "array", "items": {"type": "string"}}}
			required = ["replies"]
	return {"type": "object", "properties": props, "required": required, "additionalProperties": false}


## 发给模型的用户消息：局面、任务要求、输出格式。
static func user_prompt(task: Dictionary) -> String:
	var lines: Array[String] = ["【局面】" + String(task.get("situation", ""))]
	match String(task["kind"]):
		"npc_line":
			lines.append("【任务】以你扮演的角色说一句话（不超过 %d 字）。" % MAX_SAY)
			lines.append("只输出 JSON：{\"say\": \"台词\"}")
		"choose":
			lines.append("【任务】以你扮演的角色，从下面的选项里选一个，并说一句话（可以为空）。")
			for o: Dictionary in task.get("options", []):
				lines.append("- %s：%s" % [o["id"], o["text"]])
			lines.append("只输出 JSON：{\"choice\": \"选项 id\", \"say\": \"台词\"}")
		"persuade":
			lines.append("【任务】玩家想说服你：%s" % String(task.get("goal", "")))
			lines.append("玩家的说辞：" + String(task.get("argument", "")))
			lines.append("按你扮演的角色的立场，评估这番话的说服力：0 无效、1 弱、2 中、3 强。")
			lines.append("只输出 JSON：{\"level\": 0到3的整数, \"reason\": \"理由\"}")
		"zhushen_answer":
			lines.append("【任务】轮回者向主神提问：" + String(task.get("question", "")))
			lines.append("以主神的口吻回答：死板、庄严、不带感情。超出权限或涉及秘密的问题拒绝回答（refuse 为 true）。")
			lines.append("只输出 JSON：{\"answer\": \"回答\", \"refuse\": true 或 false}")
		"replies":
			lines.append("【任务】给玩家写 3 句可选的回复（每句不超过 %d 字），风格各不相同。" % MAX_REPLY)
			lines.append("只输出 JSON：{\"replies\": [\"……\", \"……\", \"……\"]}")
	return "\n".join(lines)


## 从模型的文字里取出 JSON 对象：容忍 ```json 代码块和前后多余的文字。取不出返回 null。
static func extract_json(text: String) -> Variant:
	var start := text.find("{")
	var end := text.rfind("}")
	if start < 0 or end <= start:
		return null
	var json := JSON.new()
	if json.parse(text.substr(start, end - start + 1)) != OK:
		return null
	return json.data if json.data is Dictionary else null


## 返回 {"ok": bool, "intent": Dictionary, "errors": [String]}。intent 只保留规定的字段。
static func validate(kind: String, data: Variant, task: Dictionary) -> Dictionary:
	var errors: Array[String] = []
	var intent := {}
	if not data is Dictionary:
		errors.append("not_object")
		return {"ok": false, "intent": intent, "errors": errors}
	match kind:
		"npc_line":
			var say := _text(data, "say", errors)
			if say == "":
				errors.append("empty_say")
			intent = {"say": say}
		"choose":
			var choice := String(data.get("choice", ""))
			var ids: Array = []
			for o: Dictionary in task.get("options", []):
				ids.append(String(o["id"]))
			if not ids.has(choice):
				errors.append("illegal_choice")
			intent = {"choice": choice, "say": _text(data, "say", errors)}
		"persuade":
			var level: Variant = data.get("level")
			if not (level is int or level is float) or float(level) != floorf(float(level)) or float(level) < 0.0 or float(level) > 3.0:
				errors.append("bad_level")
				level = 0
			intent = {"level": int(level), "reason": String(data.get("reason", ""))}
		"zhushen_answer":
			var answer := String(data.get("answer", ""))
			var refuse := bool(data.get("refuse", false))
			if answer == "":
				errors.append("empty_answer")
			if not refuse:
				for word: String in task.get("forbidden", []):
					if answer.contains(word):
						errors.append("leaks_secret")
						break
			intent = {"answer": answer, "refuse": refuse}
		"replies":
			var replies: Array = []
			var raw: Variant = data.get("replies")
			if raw is Array:
				for r in raw:
					var s := String(r).strip_edges()
					if s != "" and s.length() <= MAX_REPLY:
						replies.append(s)
			if replies.size() < 2 or replies.size() > 4:
				errors.append("bad_replies")
			intent = {"replies": replies}
		_:
			errors.append("unknown_kind")
	return {"ok": errors.is_empty(), "intent": intent, "errors": errors}


static func _text(data: Dictionary, key: String, errors: Array[String]) -> String:
	var s := String(data.get(key, "")).strip_edges()
	if s.length() > MAX_SAY:
		errors.append("too_long")
	return s

```gdscript
extends RefCounted
## 离线兜底（设计规格 8.1"离线兜底"）：没有网络、没有配置、AI 出错或输出不合格时，用规则给出确定的意图。
## 同一个任务 id 总是得到同一个结果（按 id 的哈希选台词），所以兜底也能复现。
##   npc_line：从人设的 fallback_lines 里按 id 选一句；没有就说"……"。
##   choose：选 fallback 分最高的选项，同分取第一个。
##   persuade：说辞里命中几个 keywords 就是几级（最多 3）；没有关键词时，说辞超过 20 字算 1 级，否则 0 级。
##   zhushen_answer：在 faq 里找第一个命中关键词的回答；都没命中就拒绝回答。
##   replies：用任务给的 default_replies，没有就用三句通用回复。

const REFUSAL := "此问题超出你的权限。"
const DEFAULT_REPLIES: Array[String] = ["明白了。", "我不同意。", "再说清楚一点。"]


static func respond(task: Dictionary, persona: RefCounted) -> Dictionary:
	match String(task["kind"]):
		"npc_line":
			return {"say": _line(task, persona)}
		"choose":
			var best: Dictionary = {}
			for o: Dictionary in task.get("options", []):
				if best.is_empty() or float(o.get("fallback", 0.0)) > float(best.get("fallback", 0.0)):
					best = o
			return {"choice": String(best.get("id", "")), "say": ""}
		"persuade":
			var argument := String(task.get("argument", ""))
			var keywords: Array = task.get("keywords", [])
			var level := 0
			if keywords.is_empty():
				level = 1 if argument.length() > 20 else 0
			else:
				for k: String in keywords:
					if argument.contains(k):
						level += 1
			return {"level": mini(level, 3), "reason": "离线判定"}
		"zhushen_answer":
			var question := String(task.get("question", ""))
			for item: Dictionary in task.get("faq", []):
				for k: String in item["keywords"]:
					if question.contains(k):
						return {"answer": String(item["answer"]), "refuse": false}
			return {"answer": REFUSAL, "refuse": true}
		"replies":
			var replies: Array = task.get("default_replies", DEFAULT_REPLIES)
			return {"replies": replies.duplicate()}
	return {}


static func _line(task: Dictionary, persona: RefCounted) -> String:
	if persona == null or persona.fallback_lines.is_empty():
		return "……"
	var i: int = absi(String(task["id"]).hash()) % persona.fallback_lines.size()
	return persona.fallback_lines[i]
```

## 流程：已有记录 → 直接用（replay）；没配置或没有传输层 → 离线兜底；否则组装请求 → 发出 → 解析 → 校验 → 合格就用，否则兜底。

const Intents = preload("res://ai/intents.gd")
const Fallback = preload("res://ai/fallback.gd")

func ask(task: Dictionary, persona: RefCounted, done: Callable) -> void:
	var id := String(task["id"])
	if replay.has(id):
		stats["replay"] = int(stats["replay"]) + 1
		var entry: Dictionary = replay.get_entry(id)
		done.call({"id": id, "intent": entry["intent"], "source": "replay", "reason": String(entry.get("reason", ""))})

		_fallback(task, persona, "offline", done)
		return

	var req := Providers.build_request(settings, String(task.get("tier", "fast")), Lore.text(), context, Intents.user_prompt(task), Intents.schema(kind))
	transport.send(req, func(resp: Dictionary) -> void: _on_response(task, persona, resp, done))


func _on_response(task: Dictionary, persona: RefCounted, resp: Dictionary, done: Callable) -> void:
	if not bool(resp.get("ok", false)):
		_fallback(task, persona, "transport:" + String(resp.get("error", "")), done)
		return
	var parsed := Providers.parse_response(String(settings["provider"]), int(resp.get("status", 0)), String(resp.get("body", "")))
	if not parsed["ok"]:
		_fallback(task, persona, String(parsed["error"]), done)
		return
	var kind := String(task["kind"])
	var v := Intents.validate(kind, Intents.extract_json(String(parsed["text"])), task)
	if not v["ok"]:
		_fallback(task, persona, "invalid:" + ",".join(v["errors"]), done)
		return
	var id := String(task["id"])
	replay.put(id, {"intent": v["intent"], "source": "ai", "reason": ""})
	stats["ai"] = int(stats["ai"]) + 1
	done.call({"id": id, "intent": v["intent"], "source": "ai", "reason": ""})


func _fallback(task: Dictionary, persona: RefCounted, reason: String, done: Callable) -> void:
	var id := String(task["id"])
	var intent := Fallback.respond(task, persona)
	replay.put(id, {"intent": intent, "source": "fallback", "reason": reason})
	stats["fallback"] = int(stats["fallback"]) + 1
	if reason != "offline":
		stats["last_error"] = reason
	done.call({"id": id, "intent": intent, "source": "fallback", "reason": reason})
```

```gdscript
extends Node
## 真实的传输层：用 HTTPRequest 发一次 POST，完成后回调 done({"ok", "status", "body", "error"})。
## 这个节点要挂在场景树里才能联网（例如做成自动加载）；不在树里时直接回调错误 not_in_tree。
## 流式输出（对话逐字出现）用 sse.gd 解析，等界面需要时再在这里加 HTTPClient 的流式读取。


func send(req: Dictionary, done: Callable) -> void:
	if not is_inside_tree():
		done.call({"ok": false, "status": 0, "body": "", "error": "not_in_tree"})
		return
	var http := HTTPRequest.new()
	http.timeout = float(req.get("timeout", 60.0))
	add_child(http)
	http.request_completed.connect(func(result: int, code: int, _headers: PackedStringArray, body: PackedByteArray) -> void:
		http.queue_free()
		var ok := result == HTTPRequest.RESULT_SUCCESS
		done.call({"ok": ok, "status": code, "body": body.get_string_from_utf8(), "error": "" if ok else "result_%d" % result})
	)
	var err := http.request(String(req["url"]), req["headers"], HTTPClient.METHOD_POST, String(req["body"]))
	if err != OK:
		http.queue_free()
		done.call({"ok": false, "status": 0, "body": "", "error": "request_error_%d" % err})
```

```gdscript
extends RefCounted
## 流式输出（Server-Sent Events）解析（设计规格 8.1"延迟：对话流式输出"）：一段段喂进收到的数据，吐出新增的文字。
## Anthropic：content_block_delta 里 delta.type 为 text_delta 的 text；message_delta 带 stop_reason；message_stop 表示结束。
## OpenAI 兼容：data 里 choices[0].delta.content；finish_reason；data: [DONE] 表示结束。
## 事件之间用空行分隔，数据可能在任何地方被切开，所以先攒在 buffer 里，凑齐一个事件再处理。

var provider: String = "anthropic"
var buffer: String = ""
var text: String = ""
var stop_reason: String = ""
var done: bool = false


func _init(p: String = "anthropic") -> void:
	provider = p


## 喂一段数据，返回这次新增的文字片段。
func feed(chunk: String) -> Array[String]:
	var out: Array[String] = []
	buffer += chunk.replace("\r\n", "\n")
	var sep := buffer.find("\n\n")
	while sep >= 0:
		var event := buffer.substr(0, sep)
		buffer = buffer.substr(sep + 2)
		for line in event.split("\n"):
			if line.begins_with("data:"):
				var piece := _handle(line.substr(5).strip_edges())
				if piece != "":
					out.append(piece)
					text += piece
		sep = buffer.find("\n\n")
	return out


func _handle(data: String) -> String:
	if data == "[DONE]":
		done = true
		return ""
	var json := JSON.new()
	if json.parse(data) != OK or not json.data is Dictionary:
		return ""
	var d: Dictionary = json.data
	if provider == "anthropic":
		match String(d.get("type", "")):
			"content_block_delta":
				var delta: Dictionary = d.get("delta", {})
				if delta.get("type", "") == "text_delta":
					return String(delta.get("text", ""))
			"message_delta":
				stop_reason = String((d.get("delta", {}) as Dictionary).get("stop_reason", ""))
			"message_stop":
				done = true
		return ""
	var choices: Array = d.get("choices", [])
	if choices.is_empty():
		return ""
	var c: Dictionary = choices[0]
	if c.get("finish_reason") != null:
		stop_reason = String(c["finish_reason"])
	var piece: Variant = (c.get("delta", {}) as Dictionary).get("content")
	return String(piece) if piece != null else ""
```
