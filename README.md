# 无限恐怖 · 2D 回合制同人游戏

以 zhttty 的小说《无限恐怖》为蓝本的 2D 回合制游戏：在主神空间变强，进恐怖片活下去，回来结算——暗黑地牢式的据点 + 远征 + 回合制战斗，永久死亡、恐惧值、基因锁、团战、智者布局，主神和 NPC 由 AI 接管。

引擎 Godot 4.7.2（GDScript）。现在只做 Windows 版；安卓的导出预设已经写好，安卓版和触屏交互暂缓。

## M1 现状（2026-11-10 核查）
对照规格 9.7 的完成标准：

| 标准 | 现状 |
|---|---|
| 1. 从头玩到 M1 结束不崩溃 | PC 可以：无头切片验收走完整条路线，40 局随机乱玩没有崩溃或卡死。安卓暂缓。 |
| 2. 三条可感知分歧、结算合原著 | 救不救马修、扶不扶掉队新人、留守还是跟走都改变剧情和队友信任；原著路线郑吒 6500 点。 |
| 3. 基因锁、恐惧崩溃、感染、百米绑定、禁言能触发 | 都能在游玩中触发。 |
| 4. 兑换的强化在训练场能感受到 | 训练场对练显示伤害；目录 200 条，每条都真能用。 |
| 5. 地点切换和休整期能存读档 | 自动存档 + 三个手动槽；铁人模式只有一个自动档。 |
| 6. 规则内核的无界面测试全过 | 459 个测试全过，含相对奖励曲线和原著价格锁。 |
| 7. 剧情人物、新人、主神由 AI 驱动 | 接口、人设、离线兜底都在；**还没用真实密钥在线跑过**。 |

还缺的：
- **美术**：正式的像素战斗小人和战斗背景要等 Codex 跑任务卡 006（现在是代码画的占位）；剧情 CG 还差 3 张（任务卡 005 第三批）；地点探索和主神空间还不是像素场景；没有背景音乐。
- **平衡**：按好路线走、战斗全交给 AI 的试跑里，30 局有 17 局活着回来，詹岚能活下来了（改站位前一局都活不下来）。真人玩家能说服火焰女皇、会用防御和换排，实际会容易一些，但还没做系统的数值调整。
- **没做的机制**：被动能力（狼人形态、心神凝聚等）的战斗效果，A、S 档兑换，向主神许愿，投票和诱饵（M2）。

```bash
bash game/tools/run_tests.sh
```

## 安卓导出
导出预设已经写好：横屏、arm64-v8a + armeabi-v7a、包名 `com.wuxiankongbu.game`、INTERNET 权限（AI 对话要用）。先看工具链齐不齐，再出包：

```bash
bash game/tools/check_export_env.sh   # 缺什么、去哪补，都写在输出里
bash game/tools/export_android.sh     # 产物：game/build/wuxian-kongbu.apk
```

`game/build/` 不进版本控制。这台机器目前缺安卓导出模板和 JDK 17，补齐后即可出包。

移动端注意：界面按 1920×1080 设计，`keep` 比例缩放、横屏全屏，19.5:9 的手机会有黑边；按钮按 PC 习惯做的，真机上偏小，移动布局要单独做一版。
