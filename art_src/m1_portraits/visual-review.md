## 如实保留的限制

1. 网关原生透明图的主体 alpha 主要为 253（约 99.2% 不透明），没有完整 255 像素。未强制改成 255；自动 QA 接受近不透明主体并记录警告。这在深浅底预览中未造成明显穿透，但叠在高对比背景上仍可能有轻微影响。
2. 四张原图外围淡雾由 sprite-gen 原生 `slice-sheet --alpha-floor 64` 清理，主体/邻接边缘按原生规则保留；无自写抠图或重绘。处理报告中的 `changed_solid_pixels`、`changed_edge_pixels` 均为 0，`clipped_px` 均为 0。
3. CG 请求尺寸为 1536×864，网关实际返回 1672×941；使用已有 `fit_canvas.py` 等比放大为 1919×1080，右侧补 1px 暗色至 1920×1080，没有非等比拉伸。
4. API 适配器无 seed 参数；请求与模型名、参考图来源和校验和已记录，不承诺逐像素复现。
