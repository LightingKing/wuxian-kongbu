# 像素试验共用调色板

唯一颜色来源是 `game/art/pixel_test/palette.hex`，32 个互不重复的 RGB 值。透明度不计为颜色；角色透明像素 alpha=0，可见像素 alpha=255。

| 色组 | 用途 |
|---|---|
| 1–4 | 冷黑轮廓、黑发、皮带、枪身、深灰西裤 |
| 5–10 | 冷灰金属、衬衫与大褂的阴影/亮部、走廊墙面 |
| 11–15 | 郑吒的暖肤色，与环境冷色形成区分 |
| 16–20 | 丧尸灰绿皮肤、污渍与走廊氧化金属 |
| 21–24 | 干血、血迹和局部警示色 |
| 25–28 | 枪的金属冷光、走廊设施和照明 |
| 29–31 | 枪口火光、灯光、少量警示条纹 |
| 32 | 少量冷青设施指示色 |

角色首次 extract 前写入原生 `palette.lock.json`，其 `colors` 完整复制这 32 色；pixel-unfake 的原生调色板阶段将像素映射到锁定颜色。`--fit-outline off` 防止量化后再压暗轮廓引入新色。单独声明 `palette_size=32` 只限制颜色数量，不能替代外部共享颜色锁定。背景由任务卡授权的整场景工具映射到同一文件。最终从落盘图集和背景逐像素复核颜色集合、alpha 和 SHA-256。
